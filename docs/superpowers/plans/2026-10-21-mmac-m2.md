# mMac M2 (the inspector) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** mMac gets a native resizable inspector with Git status, line-numbered diffs, diff review (revert a hunk, revert a file, stage a file), worktrees with merge and remove, file previews and the activity list, plus worktree conversations and project Git badges. M2 also closes every item M1 carried forward.

**Architecture:** The Node backend gains the eleven inspector methods, which call the fork's existing `src/main/git.ts`, `src/main/files.ts` and `src/main/worktrees.ts` unchanged. `MuseBackend` gets their typed Swift calls. A new `Inspector` store in `MuseKit` owns the inspector's state, and pure rules (diff lines, file kinds, breadcrumbs, badges, activity) sit beside it under `swift test`. The app draws the inspector with SwiftUI's `.inspector` modifier. Asks and confirmations move to `NSAlert` sheets, so they show over any sheet already open.

**Tech Stack:** TypeScript, zod, Vitest, `tsx`; Swift 6, SwiftUI (macOS 15), AppKit (`NSAlert`, `NSOpenPanel`, `NSTextView`), Swift Testing, `swift-markdown` 0.9.0, XCUITest, XcodeGen.

**Inputs:** the spec `docs/superpowers/specs/2026-10-21-mac-app-design.md` (the M2 row and the six (M2) parity items), the M1 plan's "Carried into M2" section in `docs/superpowers/plans/2026-10-21-mmac-m1.md`, `docs/decisions.md`, and Electron's inspector: `src/renderer/src/components/Inspector.tsx`, `src/renderer/src/components/WorkspacePages.tsx` (Files and Projects pages) and `src/renderer/src/activity.ts`. When this plan quotes a user-facing string, it comes from those files.

**Dom's decisions for M2 (2026-10-21):**

- File previews are a **Files** tab in the inspector, beside **Changes** and **Activity**. Electron has them on a separate page.
- Project Git badges show in the sidebar's project picker and in the inspector header. mMac gets no Projects page.
- **Ask Muse** in the diff and file views adds the path to the draft as text, with Electron's exact sentences. `@file` mentions stay in M4.
- M2 closes every item in M1's "Carried into M2" list, the M4-tagged ones included.

## Before you start

- Work on the `mac-m2` branch, cut from `origin/extensions` (which holds M1). Do not rebase it.
- Every run that starts `muse` points `HOME`, `MUSE_HOME`, `XDG_CONFIG_HOME`, `XDG_DATA_HOME`, `XDG_STATE_HOME` and `ZDOTDIR` at a temporary folder, and sets `MUSE_DESKTOP_TEST_PROVIDER=echo` and `MUSE_NO_AUTO_UPDATE=1`. `scripts/verify-headless.ts` shows how. Never run anything against the real `~/.config/muse/`.
- `export MUSE_BIN="$(command -v muse)"` before the integration and headless checks.
- Swift build output goes to `.cache/` at the repo root: `--scratch-path .cache/swift` and `.cache/swift-kit` for `swift test`, and `-derivedDataPath .cache/mmac` for `xcodebuild`.
- Never edit upstream files under `src/main/`, `src/renderer/` or `src/preload/`. M2 adds code beside them.
- Commits use the repo's `area: summary` style (`headless:`, `mac:`, `docs:`) and end with the `Co-Authored-By` line the session gives you.
- Swift 6 language mode reports data races as errors. Fix them; never add `@unchecked Sendable` or `nonisolated(unsafe)` beyond what this plan shows.
- UI-test screen capture stays off (`captureScreenshotsAutomatically: false`).
- Electron's behaviour is the default. Where this plan differs on purpose, the task says so, and Task 20 records it in `docs/decisions.md`.

```swift
/// Fires once. Waiters resume when it fires or when their task is cancelled.
final class OneShot: @unchecked Sendable {
  private let lock = NSLock()
  private var fired = false
  private var waiters: [UUID: CheckedContinuation<Void, Never>] = [:]

  func fire() {
    let waiting = lock.withLock { () -> [CheckedContinuation<Void, Never>] in
      guard !fired else { return [] }
      fired = true
      defer { waiters = [:] }
      return Array(waiters.values)
    }
    for waiter in waiting { waiter.resume() }
  }

  func wait() async {
    let id = UUID()
    await withTaskCancellationHandler {
      await withCheckedContinuation { continuation in
        let resumeNow = lock.withLock { () -> Bool in
          if fired || Task.isCancelled { return true }
          waiters[id] = continuation
          return false
        }
        if resumeNow { continuation.resume() }
      }
    } onCancel: {
      lock.withLock { waiters.removeValue(forKey: id) }?.resume()
    }
  }
}
```

```swift
  /// Runs `process` and returns its stdout once stdout closes, or after `timeout` seconds.
  /// It returns nil if the process is still running then, and kills it with SIGKILL, because an
  /// interactive shell ignores SIGTERM. A child the process started, such as a daemon from a
  /// shell's start-up files, can hold stdout open after the process exits. That case returns
  /// what was read by the deadline. No thread waits meanwhile.
  static func output(of process: Process, timeout: TimeInterval) async -> Data? {
    let pipe = Pipe()
    let state = OutputState()
    process.standardOutput = pipe
    process.terminationHandler = { _ in state.markExited() }
    return await withCheckedContinuation { continuation in
      state.continuation = continuation
      let reader = PipeReader(
        pipe.fileHandleForReading, received: { state.append($0) }, ended: { state.finish() })
      do { try process.run() } catch {
        reader.end()
        try? pipe.fileHandleForWriting.close()
        state.giveUp()
        return
      }
      let pid = process.processIdentifier
      DispatchQueue.global().asyncAfter(deadline: .now() + timeout) {
        // Still running at the deadline: kill it and return nil. Exited, but a child holds
        // stdout: return what was read.
        if state.stillRunning {
          kill(pid, SIGKILL)
          state.giveUp()
        }
        reader.end()
      }
    }
  }
```

```swift
/// What `Launcher.output` has read, and its one reply.
private final class OutputState: @unchecked Sendable {
  private let lock = NSLock()
  private var data = Data()
  private var exited = false
  private var replied = false
  var continuation: CheckedContinuation<Data?, Never>?

  func append(_ chunk: Data) { lock.withLock { data.append(chunk) } }
  func markExited() { lock.withLock { exited = true } }
  var stillRunning: Bool { lock.withLock { !exited } }

  /// stdout ended, or the deadline passed with the process gone: reply with what was read.
  func finish() { reply(lock.withLock { data }) }
  /// The process could not start, or was killed at the deadline.
  func giveUp() { reply(nil) }

  private func reply(_ value: Data?) {
    let waiting = lock.withLock { () -> CheckedContinuation<Data?, Never>? in
      guard !replied else { return nil }
      replied = true
      return continuation
    }
    waiting?.resume(returning: value)
  }
}

    let process = Process()
    process.executableURL = URL(fileURLWithPath: loginShell)
    process.arguments = ["-ilc", #"printf '\0MMAC_ENV\0'; /usr/bin/env -0"#]
    process.standardError = FileHandle.nullDevice
    process.standardInput = FileHandle.nullDevice
    return await output(of: process, timeout: 6).flatMap(parseLoginEnvironment)

  /// The `KEY=VALUE` records after the `MMAC_ENV` marker. Shell start-up output before it is ignored.
  static func parseLoginEnvironment(_ data: Data) -> [String: String]? {
    let marker = Data([0]) + Data("MMAC_ENV".utf8) + Data([0])
    guard let range = data.range(of: marker) else { return nil }
    var environment: [String: String] = [:]
    for record in data[range.upperBound...].split(separator: 0) {
      let text = String(decoding: record, as: UTF8.self)
      guard let equals = text.firstIndex(of: "="), equals != text.startIndex else { continue }
      environment[String(text[..<equals])] = String(text[text.index(after: equals)...])
    }
    return environment
  }

import Foundation
import MuseBackend

/// One row of a diff, as Electron's `parseDiffLines` in `Inspector.tsx`.
public struct DiffLine: Equatable, Sendable, Identifiable {
  public enum Kind: Equatable, Sendable { case meta, hunk, added, removed, context }

  /// The row's position. A diff is replaced whole, never edited, so position is identity.
  public let id: Int
  public let kind: Kind
  public let oldNumber: Int?
  public let newNumber: Int?
  public let text: String
  /// On a working-tree hunk header: the hunk's index, counted from 0, for `revertHunk`. Hunks in
  /// the "Staged changes" section have none, because `revertHunk` counts the working diff only.
  public let hunkIndex: Int?

  /// The one gutter Electron draws: the new line number, else the old one.
  public var gutter: String { (newNumber ?? oldNumber).map(String.init) ?? "" }

  /// Differs from Electron in three ways: a final newline adds no empty row, a
  /// `\ No newline at end of file` line is meta, and an untracked file's lines (which
  /// `getGitDiff` writes with no hunk header) are numbered from 1.
  public static func parse(_ diff: String) -> [DiffLine] {
    var lines = diff.components(separatedBy: "\n")
    if diff.hasSuffix("\n") { lines.removeLast() }
    var rows: [DiffLine] = []
    var oldLine = 0
    var newLine = 0
    var working = false
    var workingHunks = 0
    var newFile = false
    func add(_ kind: Kind, _ text: String, old: Int? = nil, new: Int? = nil, hunk: Int? = nil) {
      rows.append(DiffLine(id: rows.count, kind: kind, oldNumber: old, newNumber: new, text: text, hunkIndex: hunk))
    }
    for line in lines {
      if line == "Staged changes" || line == "Working changes" {
        working = line == "Working changes"
        add(.meta, line)
      } else if let (old, new) = hunkStart(line) {
        oldLine = old
        newLine = new
        add(.hunk, line, hunk: working ? workingHunks : nil)
        if working { workingHunks += 1 }
      } else if line.hasPrefix("---") || line.hasPrefix("+++") || line.hasPrefix("diff ")
        || line.hasPrefix("index ") || line.hasPrefix("\\")
      {
        if line == "--- /dev/null" { newFile = true }
        if line.hasPrefix("+++"), newFile, newLine == 0 { newLine = 1 }
        add(.meta, line)
      } else if line.hasPrefix("+") {
        add(.added, line, new: take(&newLine))
      } else if line.hasPrefix("-") {
        add(.removed, line, old: take(&oldLine))
      } else {
        add(.context, line, old: take(&oldLine), new: take(&newLine))
      }
    }
    return rows
  }

  /// The counter's value, then one more. Nil while no hunk has set it, as Electron's `n ? n++ : ''`.
  private static func take(_ counter: inout Int) -> Int? {
    guard counter > 0 else { return nil }
    defer { counter += 1 }
    return counter
  }

  // Built once. NSRegularExpression is immutable and documented as thread-safe.
  static let hunkHeader = try! NSRegularExpression(pattern: #"^@@ -(\d+)(?:,\d+)? \+(\d+)(?:,\d+)? @@"#)

  static func hunkStart(_ line: String) -> (Int, Int)? {
    guard let match = hunkHeader.firstMatch(in: line, range: NSRange(line.startIndex..., in: line)),
      let old = Range(match.range(at: 1), in: line), let new = Range(match.range(at: 2), in: line)
    else { return nil }
    return (Int(line[old]) ?? 0, Int(line[new]) ?? 0)
  }
}

    }
    if item.kind == "hookRun" { return ToolPresentation.first(item.label) ?? "CLI hook" }

  static func detail(_ item: TranscriptItem) -> String {

      return (item.blocking == true ? "Keeps the turn open · " : "")
        + (item.status == "inProgress" ? "Running" : item.status)
    }
    return ToolPresentation.first(item.statusLine, item.objective, item.fallbackText) ?? item.status
  }

      if character.isUppercase { text += " " }
      text.append(character)
    }
    return spaced.prefix(1).uppercased() + spaced.dropFirst()
  }
}

  }

```swift
import Foundation
import MuseBackend
import Observation

/// The inspector's state for one project: Git status and the open diff, the review actions, Muse
/// worktrees, and the Files tab. Electron keeps the same state in `Inspector.tsx` and the Files
/// page in `WorkspacePages.tsx`. The Workspace owns one and points it at its current project.
@MainActor @Observable
public final class Inspector {
  public enum Tab: String, CaseIterable, Sendable { case changes, files, activity }

  /// Something that loads after a click: a diff or a file preview.
  public enum Loadable<Value: Equatable & Sendable>: Equatable, Sendable {
    case idle
    case loading
    case loaded(Value)
    /// The backend's message, which is written for the person.
    case failed(String)
  }

  public var tab: Tab = .changes
  public private(set) var project: String
  public private(set) var git: GitStatus?
  public private(set) var worktrees: [WorktreeEntry] = []
  public private(set) var loading = false
  /// Why the status could not be read.
  public private(set) var error: String?
  /// The changed file whose diff shows.
  public private(set) var selected: String?
  public private(set) var diff: Loadable<[DiffLine]> = .idle
  /// True while a review or worktree action runs. The buttons are disabled meanwhile.
  public private(set) var busy = false
  /// A successful merge's message, until the next action.
  public private(set) var notice: String?

  /// The Files tab's folder, relative to the project root. Empty is the root.
  public private(set) var directory = ""
  public private(set) var files: [ProjectFile] = []
  public private(set) var filesLoading = false
  public private(set) var filesError: String?
  /// "Find in this folder…".
  public var query = ""
  public private(set) var previewPath: String?
  public private(set) var preview: Loadable<String> = .idle

  let client: BackendClient
  /// Shows an action's failure. The Workspace sets it to its window alert.
  @ObservationIgnored var reportError: @MainActor (String) -> Void = { _ in }
  /// Receives each status read, so the sidebar's badge for this project stays current.
  @ObservationIgnored var statusRead: @MainActor (String, GitStatus) -> Void = { _, _ in }

  /// Bumped by `show(project:)`. A reply for an earlier project compares it and is dropped.
  private var generation = 0
  private var refreshSequence = 0
  private var diffSequence = 0
  private var filesSequence = 0
  private var previewSequence = 0

  init(client: BackendClient, project: String) {
    self.client = client
    self.project = project
  }

  /// Shows another project. Everything resets, as Electron remounts its inspector per project.
  func show(project: String) {
    guard project != self.project else { return }
    generation += 1
    self.project = project
    git = nil
    worktrees = []
    loading = false
    error = nil
    selected = nil
    diff = .idle
    busy = false
    notice = nil
    directory = ""
    files = []
    filesLoading = false
    filesError = nil
    query = ""
    previewPath = nil
    preview = .idle
  }

  /// Muse-created worktrees (`<project>/.muse/worktrees/<name>`), which get Merge and Remove.
  public var museWorktrees: [WorktreeEntry] {
    worktrees.filter { ProjectPath.worktreeParent($0.path) != nil }
  }

  /// The branch a merge goes into, as Electron names it.
  public var mainBranch: String {
    worktrees.first(where: \.isMain)?.branch.flatMap { $0.isEmpty ? nil : $0 } ?? "the main checkout"
  }

  public var visibleFiles: [ProjectFile] {
    let needle = query.lowercased()
    return needle.isEmpty ? files : files.filter { $0.name.lowercased().contains(needle) }
  }

  // MARK: Changes

  /// Reads the worktrees and the status. The open diff stays, and reloads, while its file still
  /// has changes; it closes when the file has none.
  public func refresh() async {
    guard !project.isEmpty else { return }
    let project = self.project
    let generation = self.generation
    refreshSequence += 1
    let sequence = refreshSequence
    func current() -> Bool { sequence == refreshSequence && generation == self.generation }
    loading = true
    error = nil
    defer { if current() { loading = false } }
    // As Electron: a folder Muse cannot list worktrees for simply has none.
    let list = (try? await client.worktrees(project: project)) ?? []
    guard current() else { return }
    worktrees = list
    do {
      let status = try await client.gitStatus(project: project)
      guard current() else { return }
      git = status
      statusRead(project, status)
      if let selected {
        if status.changes.contains(where: { $0.path == selected }) { await loadDiff() } else { close() }
      }
    } catch is CancellationError {
      // The caller stopped waiting; the next refresh reads the status.
    } catch {
      guard current() else { return }
      self.error = error.localizedDescription
    }
  }

  public func select(_ path: String) async {
    selected = path
    diff = .loading
    await loadDiff()
  }

  /// Back to the list of changed files.
  public func close() {
    selected = nil
    diffSequence += 1
    diff = .idle
  }

  /// Loads the selected file's diff. A reload keeps the rows shown until the new ones arrive.
  private func loadDiff() async {
    guard let path = selected else { return }
    let project = self.project
    let generation = self.generation
    diffSequence += 1
    let sequence = diffSequence
    do {
      let text = try await client.gitDiff(project: project, path: path)
      guard sequence == diffSequence, generation == self.generation else { return }
      diff = .loaded(DiffLine.parse(text))
    } catch {

    } catch {

    }
    guard generation == self.generation else { return }

    notice = shown
    // A cancelled caller cannot wait for a refresh. The next one shows the result.
    if !Task.isCancelled { await refresh() }
  }

      files = list
    } catch {

      filesError = error.localizedDescription

````swift
import Foundation

/// GFM footnotes, which swift-markdown does not parse. remark-gfm draws a reference `[^a]` as a
/// small number and lists the notes at the end. This rewrites the source before parsing: each
/// reference becomes a superscript number, in order of first use, and the definitions used become
/// a numbered list after a rule. Code blocks and code spans are left alone. An unused definition
/// is dropped, and a reference with no definition stays as typed, as in remark-gfm.
enum Footnotes {
  // Built once. NSRegularExpression is immutable and documented as thread-safe.
  static let definition = try! NSRegularExpression(pattern: #"^ {0,3}\[\^([^\]\s]+)\]:[ \t]?(.*)$"#)
  static let reference = try! NSRegularExpression(pattern: #"\[\^([^\]\s]+)\]"#)
  static let superscripts: [Character] = ["⁰", "¹", "²", "³", "⁴", "⁵", "⁶", "⁷", "⁸", "⁹"]

  static func rewrite(_ source: String) -> String {
    guard source.contains("[^") else { return source }
    var body: [String] = []
    var definitions: [String: String] = [:]
    var fence: Substring?
    var continuing: String?
    for line in source.components(separatedBy: "\n") {
      let trimmed = line.drop { $0 == " " }
      if let open = fence {
        body.append(line)
        if trimmed.hasPrefix(open) { fence = nil }
        continue
      }
      if trimmed.hasPrefix("```") || trimmed.hasPrefix("~~~") {
        fence = trimmed.prefix(3)
        continuing = nil
        body.append(line)
        continue
      }
      if let groups = captures(definition, line) {
        if definitions[groups[0]] == nil { definitions[groups[0]] = groups[1] }
        continuing = groups[0]
        continue
      }
      // An indented line right after a definition continues it.
      if let label = continuing, line.hasPrefix("    ") || line.hasPrefix("\t") {
        definitions[label, default: ""] += " " + line.trimmingCharacters(in: .whitespaces)
        continue
      }
      continuing = nil
      body.append(line)
    }
    guard !definitions.isEmpty else { return source }

    var order: [String] = []
    fence = nil
    let rewritten = body.map { line -> String in
      let trimmed = line.drop { $0 == " " }
      if let open = fence {
        if trimmed.hasPrefix(open) { fence = nil }
        return line
      }
      if trimmed.hasPrefix("```") || trimmed.hasPrefix("~~~") {
        fence = trimmed.prefix(3)
        return line
      }
      return replacingReferences(in: line) { label in
        guard definitions[label] != nil else { return nil }
        if !order.contains(label) { order.append(label) }
        return superscript(order.firstIndex(of: label)! + 1)
      }
    }
    let text = rewritten.joined(separator: "\n")
    guard !order.isEmpty else { return text }
    let notes = order.enumerated().map { "\($0.offset + 1). \(definitions[$0.element] ?? "")" }
    return text + "\n\n---\n\n" + notes.joined(separator: "\n") + "\n"
  }

  /// Replaces references outside code spans. A span is text between backticks.
  static func replacingReferences(in line: String, _ replacement: (String) -> String?) -> String {
    guard line.contains("[^") else { return line }
    return line.components(separatedBy: "`").enumerated().map { index, part in
      index % 2 == 1 ? part : replacingMatches(in: part, replacement)
    }.joined(separator: "`")
  }

  static func replacingMatches(in text: String, _ replacement: (String) -> String?) -> String {
    let matches = reference.matches(in: text, range: NSRange(text.startIndex..., in: text))
    // Numbered in reading order, then replaced from the end, so earlier ranges stay valid.
    let found = matches.compactMap { match -> (Range<String.Index>, String)? in
      guard let whole = Range(match.range, in: text), let label = Range(match.range(at: 1), in: text),
        let new = replacement(String(text[label]))
      else { return nil }
      return (whole, new)
    }
    var result = text
    for (range, new) in found.reversed() { result.replaceSubrange(range, with: new) }
    return result
  }

  static func superscript(_ number: Int) -> String {
    String(String(number).compactMap { $0.wholeNumberValue.map { superscripts[$0] } })
  }

  static func captures(_ expression: NSRegularExpression, _ line: String) -> [String]? {
    guard let match = expression.firstMatch(in: line, range: NSRange(line.startIndex..., in: line)) else {
      return nil
    }
    return (1..<match.numberOfRanges).map { Range(match.range(at: $0), in: line).map { String(line[$0]) } ?? "" }
  }
}
````

  /// Valid JSON laid out as `JSON.stringify(value, null, 2)` lays it out: two-space indents,
  /// `"key": value`, `{}` and `[]` on one line, keys in their own order. Every token stays as
  /// typed, so numbers and string escapes are not reformatted. Anything else comes back unchanged.
  public static func formattedArgs(_ args: String) -> String {
    guard (try? JSONDecoder().decode(JSONValue.self, from: Data(args.utf8))) != nil else { return args }
    var out = ""
    var indent = 0
    var inString = false
    var escaped = false
    let characters = Array(args)
    var index = 0
    func newline() { out += "\n" + String(repeating: "  ", count: indent) }
    while index < characters.count {
      let character = characters[index]
      if inString {
        out.append(character)
        if escaped { escaped = false } else if character == "\\" { escaped = true } else if character == "\"" { inString = false }
        index += 1
        continue
      }
      switch character {
      case "\"":
        inString = true
        out.append(character)
      case "{", "[":
        var next = index + 1
        while next < characters.count, " \t\n\r".contains(characters[next]) { next += 1 }
        if next < characters.count, characters[next] == (character == "{" ? "}" : "]") {
          out.append(character)
          out.append(characters[next])
          index = next
        } else {
          out.append(character)
          indent += 1
          newline()
        }
      case "}", "]":
        indent -= 1
        newline()
        out.append(character)
      case ",":
        out.append(character)
        newline()
      case ":":
        out += ": "
      case " ", "\t", "\n", "\r":
        break
      default:
        out.append(character)
      }
      index += 1
    }
    return out
  }
```

import AppKit

/// Lets a caller close an alert that is still showing.
@MainActor
final class AlertToken {
  fileprivate var dismiss: (() -> Void)?
  /// Closes the alert, which then answers -1.
  func close() { dismiss?() }
}

/// Alerts and open panels as sheets on mMac's window. An alert goes on top of any sheet already
/// open there, such as Rename, so an Ask that the rename starts still shows.
@MainActor
enum SheetAlert {
  /// The window a new sheet attaches to: the front-most sheet of the main window. With no window
  /// showing, waits up to `limit` for one, since an Ask reopens the window first.
  static func host(waitingUpTo limit: Duration = .zero) async -> NSWindow? {
    let deadline = ContinuousClock.now + limit
    while true {
      if let window = NSApp.mainWindow ?? NSApp.windows.first(where: { $0.isVisible && $0.canBecomeMain }) {
        var front = window
        // A sheet is itself a window, and can carry a sheet of its own.
        while let sheet = front.attachedSheet { front = sheet }
        return front
      }
      if ContinuousClock.now >= deadline { return nil }
      try? await Task.sleep(for: .milliseconds(50))
    }
  }

  /// Shows an alert and returns the chosen button's index, or -1 when it was closed through
  /// `token` or no window showed. The last button is the default and the cancel choice, as in
  /// every Electron dialog the Asks replace: Return and Escape both choose it.
  static func present(
    title: String, message: String, detail: String? = nil, buttons: [String], token: AlertToken? = nil
  ) async -> Int {
    guard !buttons.isEmpty, let window = await host(waitingUpTo: .seconds(1)) else { return -1 }
    let alert = NSAlert()
    alert.messageText = title
    alert.informativeText = [message, detail].compactMap { $0 }.filter { !$0.isEmpty }.joined(separator: "\n\n")
    // NSAlert puts the first button it is given on the right and gives it Return. The last
    // button is the default, so they go in reverse, and read left to right in the Ask's order.
    for title in buttons.reversed() { alert.addButton(withTitle: title) }
    // NSAlert gives Escape only to a button titled Cancel. Escape always chooses the default here.
    for button in alert.buttons where button.keyEquivalent == "\u{1b}" { button.keyEquivalent = "" }
    let escape = NSEvent.addLocalMonitorForEvents(matching: .keyDown) { [weak alert] event in
      guard let alert, event.window === alert.window, event.keyCode == 53 else { return event }
      window.endSheet(alert.window, returnCode: .alertFirstButtonReturn)
      return nil
    }
    token?.dismiss = { [weak alert] in
      if let alert { window.endSheet(alert.window, returnCode: .abort) }
    }
    let response = await alert.beginSheetModal(for: window)
    if let escape { NSEvent.removeMonitor(escape) }
    token?.dismiss = nil
    let offset = response.rawValue - NSApplication.ModalResponse.alertFirstButtonReturn.rawValue
    guard (0..<buttons.count).contains(offset) else { return -1 }
    return buttons.count - 1 - offset
  }

  /// Runs an open panel as a sheet on the window, or on its own when no window shows.
  static func run(_ panel: NSOpenPanel) async -> URL? {
    let response =
      if let window = await host() {
        await panel.beginSheetModal(for: window)
      } else {
        await panel.begin()
      }
    return response == .OK ? panel.url : nil
  }
}

import MuseBackend

/// Asks from the backend, shown one at a time as alert sheets, in the order they came.
@MainActor
final class AskQueue {
  /// Bumped by `cancelAll`. A backend's Asks carry the generation it started in.
  private(set) var generation = 0
  /// The Ask on screen, so `cancelAll` can close it.
  private var showing: AlertToken?
  /// Ends once every earlier Ask is answered.
  private var last: Task<Void, Never>?

  /// Shows `ask` when every earlier one is answered, and returns the chosen button's index.
  /// An Ask from an older generation, whose backend the queue was cancelled for, returns -1.
  func present(_ ask: Ask, generation: Int) async -> Int {
    guard generation == self.generation else { return -1 }
    let previous = last
    let turn = Task { @MainActor [weak self] () -> Int in
      await previous?.value
      guard let self, generation == self.generation else { return -1 }
      let token = AlertToken()
      showing = token
      defer { if showing === token { showing = nil } }
      return await SheetAlert.present(
        title: ask.title, message: ask.message, detail: ask.detail, buttons: ask.buttons, token: token)
    }
    last = Task { _ = await turn.value }
    return await turn.value
  }

  /// Answers every waiting Ask with -1, the cancel choice. Used when the backend stops.
  func cancelAll() {
    generation += 1
    showing?.close()
    showing = nil

import AppKit

/// Long text in a selectable, read-only `NSTextView`: file previews and tool output. AppKit's text
/// system draws a megabyte quickly, where a SwiftUI `Text` does not. Lines do not wrap, as code.
struct ReadOnlyTextView: NSViewRepresentable {
  let text: String
  var identifier = ""
  var font = NSFont.monospacedSystemFont(ofSize: NSFont.smallSystemFontSize, weight: .regular)
  /// Receives the height the text needs, for a box that grows with it up to a limit.
  var measuredHeight: Binding<CGFloat>?

  func makeNSView(context: Context) -> NSScrollView {
    let scroll = NSTextView.scrollableTextView()
    scroll.drawsBackground = false
    scroll.hasHorizontalScroller = true
    scroll.autohidesScrollers = true
    guard let textView = scroll.documentView as? NSTextView else { return scroll }
    textView.isEditable = false
    textView.isSelectable = true
    textView.isRichText = false
    textView.drawsBackground = false
    textView.textColor = .labelColor
    textView.textContainerInset = NSSize(width: 6, height: 6)
    textView.isHorizontallyResizable = true
    textView.maxSize = NSSize(width: CGFloat.greatestFiniteMagnitude, height: CGFloat.greatestFiniteMagnitude)
    textView.textContainer?.widthTracksTextView = false
    textView.textContainer?.containerSize = NSSize(
      width: CGFloat.greatestFiniteMagnitude, height: CGFloat.greatestFiniteMagnitude)
    if !identifier.isEmpty { textView.setAccessibilityIdentifier(identifier) }
    return scroll
  }

  func updateNSView(_ scroll: NSScrollView, context: Context) {
    guard let textView = scroll.documentView as? NSTextView else { return }
    if textView.string != text {
      textView.string = text
      textView.font = font
    }
    guard let measuredHeight, let layout = textView.layoutManager, let container = textView.textContainer
    else { return }
    layout.ensureLayout(for: container)
    // Room for a horizontal scroll bar, so the last line is not hidden under it.
    let height = ceil(layout.usedRect(for: container).height + textView.textContainerInset.height * 2 + 14)
    if measuredHeight.wrappedValue != height {
      Task { @MainActor in measuredHeight.wrappedValue = height }
    }
  }
