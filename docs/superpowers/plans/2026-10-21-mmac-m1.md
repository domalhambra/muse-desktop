# mMac M1 (the core loop) Implementation Plan

**Status:** built on 2026-10-21 on the `mac-m1` branch. The code differs from this plan where review asked for it. For example, the composer is a native `NSTextView`, not a `TextField`, so Shift-Return adds a line at the cursor, and `MuseKit` runs 86 tests. The decisions behind each difference are in `docs/decisions.md`, under "2026-10-21: mMac M1". The Task 14 live check ran in an isolated run: a temporary `HOME`, the echo CLI and a Debug build. It covered the sidebar at its default width, Shift-Return and composer growth, the trust sheet (Cancel and Trust project), a running turn with Queue next, Steer now and Stop Muse, the code block's label and Copy, closing and reopening the window with no second backend, and an idle Cmd-Q that leaves no process. `~/.config/muse/` stayed untouched. It did not cover the rest of the Task 9 to 12 checklists, which "Carried into M2" lists. The live check found two bugs, fixed in `3107d74`, `bfac5b2` and `f2d4e5f`: the sidebar row showed "Untitled conversation" after the first turn, and the composer footnote wrapped onto four lines. The work M1 leaves open is in "Carried into M2" at the end.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** mMac does the everyday work of the Electron app's chat: projects and the conversation list, streamed transcripts with Markdown and code blocks, a composer that sends, stops, queues and steers, approvals, agent questions, and model and effort choice.

**Architecture:** The Node backend gains the eight M1 methods, moved into a `createBackend()` module that unit tests can drive with a fake `MuseHost`. A new Swift package, `MuseKit`, holds everything that is logic rather than drawing: Markdown parsing (Apple's `swift-markdown`), transcript grouping, the sidebar's sections, the question form's rules and a `Workspace` store that owns the conversation state. The app target keeps only SwiftUI views, the process lifecycle and native panels.

**Tech Stack:** TypeScript, zod, Vitest, `tsx`; Swift 6, SwiftUI (macOS 15), Swift Testing, `swift-markdown` 0.9.0, XCUITest, XcodeGen.

**Inputs:** the spec `docs/superpowers/specs/2026-10-21-mac-app-design.md`, the M0 plan's "Carried into M1" section in `docs/superpowers/plans/2026-10-21-mmac-m0.md`, and the parity survey `docs/superpowers/plans/2026-10-21-mmac-m1-electron-survey.md`. The survey gives every Electron string, call shape and edge case. When this plan quotes a user-facing string, it comes from the survey.

**Dom's decisions for M1 (2026-10-21):** Markdown uses Apple's `swift-markdown` with mMac's own SwiftUI views. Approvals and questions are inline cards at the end of the transcript, as in Electron.

## Before you start

- Work on the `mac-m1` branch, cut from `origin/extensions` (which holds M0). Do not rebase it.
- Every run that starts `muse` points `HOME`, `MUSE_HOME`, `XDG_CONFIG_HOME`, `XDG_DATA_HOME` and `XDG_STATE_HOME` at a temporary folder, sets `MUSE_DESKTOP_TEST_PROVIDER=echo` and `MUSE_NO_AUTO_UPDATE=1`. `scripts/verify-headless.ts` shows how. Never run anything against the real `~/.config/muse/`.
- `export MUSE_BIN="$(command -v muse)"` before the integration and headless checks.
- Swift build output goes to `.cache/` at the repo root: `--scratch-path .cache/swift` for `swift test` and `-derivedDataPath .cache/mmac` for `xcodebuild`.
- The echo provider returns no models and never raises an approval or a question. Those paths are proved by unit tests with fakes and by UI tests against a fake backend (Task 13), not by the echo CLI.
- Never edit upstream files under `src/main/`, `src/renderer/` or `src/preload/`. M1 adds code beside them.
- Commits use the repo's `area: summary` style and end with the `Co-Authored-By` line the session gives you.
- Swift 6 language mode reports data races as errors. Fix them; never add `@unchecked Sendable` or `nonisolated(unsafe)` beyond what this plan shows.

This is the method code from the current `src/headless/server.ts`, moved. Three things change: `wire.ask` becomes the `ask` callback, the `quitting` flag becomes the `quitting()` callback, and `setImmediate(() => void quit(n))` becomes `quit(n)` (the server schedules it).

```ts
import { mkdir, realpath, stat } from 'node:fs/promises'
import { basename, join } from 'node:path'
import { z } from 'zod'
import {
  effortSchema,
  preferencesSchema,
  type AppEvent,
  type Preferences,
} from '../shared/protocol'
import type { MuseHost } from '../main/muse-host'
import { readPreferences, writePreferences } from '../main/preferences'
import { projectRoot, worktreeParent } from '../shared/worktree'
import { HEADLESS_PROTOCOL, type Ask, type Method } from './wire'

// mMac's backend methods and the state they share. src/headless/server.ts owns
// stdin, stdout and the quit path, so unit tests can drive these methods with a
// fake MuseHost (tests/unit/headless-backend.test.ts). This repeats the wiring of
// src/main/index.ts instead of sharing it, so upstream syncs of index.ts stay
// clean; tests/unit/headless-parity.test.ts catches drift between the two.

/** The parts of MuseHost the methods use. */
export type Muse = Pick<
  MuseHost,
  | 'status'
  | 'connect'
  | 'list'
  | 'create'
  | 'open'
  | 'send'
  | 'cancel'
  | 'getSession'
  | 'hasActiveTurns'
>

export type BackendDeps = {
  muse: Muse
  /** Shows a native alert in mMac and resolves with the chosen button's index, or -1. */
  ask: (ask: Ask) => Promise<number>
  emit: (event: AppEvent) => void
  version: string
  /** True once the quit path has started. */
  quitting: () => boolean
  /** Starts the quit path. The server runs it after the current Reply is written. */
  quit: (code: number) => void
}

export function createBackend({ muse, ask, emit, version, quitting, quit }: BackendDeps) {
  const id = z.string().min(1).max(200)
  const pathSchema = z.string().min(1).max(4096)
  const methods = new Map<string, Method>()
  let greeted = false
  let starting = false
  let preferences: Preferences | undefined
  let preferencePath = ''
  let preferenceWrites: Promise<void> = Promise.resolve()

  // Register every method with a literal call to method, name in quotes as the first argument:
  // tests/unit/headless-parity.test.ts finds them by that pattern.
  function method(name: string, action: Method) {
    methods.set(name, async (...args: unknown[]) => {
      if (name !== 'hello' && !greeted) throw new Error('Send hello first.')
      if (!['hello', 'start', 'shutdown'].includes(name) && !preferences)
        throw new Error('Send start first.')
      return action(...args)
    })
  }

  function current() {
    if (!preferences) throw new Error('Send start first.')
    return preferences
  }

  async function savePreferences(patch: Partial<Preferences>) {
    const write = preferenceWrites.then(async () => {
      const snapshot = preferencesSchema.parse({ ...current(), ...patch })
      await writePreferences(preferencePath, snapshot)
      preferences = snapshot
      emit({ type: 'preferences', preferences: snapshot })
      return snapshot
    })
    preferenceWrites = write.then(
      () => {},
      () => {},
    ) // A failed write must not block later saves.
    return write
  }

  async function knownProject(value: unknown) {
    const project = await realpath(pathSchema.parse(value))
    const resolvedRecent = await Promise.all(
      current().recentProjects.map(async (entry) => {
        try {
          return await realpath(entry)
        } catch {
          return entry
        }
      }),
    )
    // A Muse-created worktree (`<project>/.muse/worktrees/<name>`) belongs to its project.
    const candidates = [project, worktreeParent(project)].filter((entry) => entry !== null)
    if (!resolvedRecent.some((entry) => candidates.includes(entry)))
      throw new Error('Choose this project using Open project first.')
    return project
  }

  async function trustProject(project: string) {
    const { trustedProjects } = current()
    if (trustedProjects.includes(project)) return
    const parent = worktreeParent(project)
    if (parent && trustedProjects.includes(parent)) return
    const choice = await ask({
      kind: 'confirm',
      title: 'Trust this project?',
      message: `Work with Muse in “${basename(project)}”?`,
      detail: `Muse can read and edit this project and use its skills, instructions, and hooks. Its existing sandbox and tool approval settings remain active.\n\n${project}\n\nOnly continue with a project you trust.`,
      buttons: ['Trust project', 'Cancel'],
    })
    if (choice !== 0) throw new Error('Project trust was cancelled. No session was started.')
    await savePreferences({ trustedProjects: [...current().trustedProjects, project] })
  }

  async function sessionProject(sessionId: string) {
    const session = muse.getSession(sessionId)
    if (!session.workspaceRoot) throw new Error('This conversation has no project folder.')
    const project = await realpath(session.workspaceRoot)
    await trustProject(project)
    return project
  }

  method('hello', (value) => {
    const theirs = z.number().int().parse(value)
    if (theirs !== HEADLESS_PROTOCOL) {
      quit(2)
      throw new Error(
        `mMac speaks backend protocol ${theirs}, but this backend speaks ${HEADLESS_PROTOCOL}. Build mMac and the backend from the same checkout.`,
      )
    }
    greeted = true
    return { protocol: HEADLESS_PROTOCOL, version }
  })

  method('start', async (value) => {
    if (quitting()) throw new Error('The backend is quitting.')
    if (starting || preferences) throw new Error('The backend has already started.')
    starting = true
    try {
      const { dataFolder } = z.object({ dataFolder: pathSchema }).parse(value)
      await mkdir(dataFolder, { recursive: true, mode: 0o700 })
      preferencePath = join(dataFolder, 'preferences.json')
      preferences = await readPreferences(preferencePath)
    } catch (error) {
      starting = false
      throw error
    }
    if (quitting()) throw new Error('The backend is quitting.')
    const status = await muse.connect(preferences.cliPath)
    return { preferences, status }
  })

  method('connect', async () => {
    if (quitting()) throw new Error('The backend is quitting.')
    if (muse.hasActiveTurns()) {
      const choice = await ask({
        kind: 'confirm',
        title: 'Reconnect while Muse is working?',
        message:
          'Reconnecting closes the current CLI host and interrupts its active turns. Saved conversations can be resumed afterward.',
        buttons: ['Reconnect', 'Cancel'],
      })
      if (choice !== 0) return muse.status
    }
    if (quitting()) throw new Error('The backend is quitting.')
    return muse.connect(current().cliPath)
  })

  method('add-project', async (value) => {
    const project = await realpath(pathSchema.parse(value))
    if (!(await stat(project)).isDirectory()) throw new Error('Choose a folder, not a file.')
    await savePreferences({
      recentProjects: [
        project,
        ...current().recentProjects.filter((entry) => entry !== project),
      ].slice(0, 30),
    })
    return project
  })

  method('sessions', async (cursor) => {
    const result = await muse.list(z.string().optional().parse(cursor))
    const roots = [
      ...new Set(
        result.sessions
          .filter((session) => session.kind !== 'subagent')
          .map((session) => session.workspaceRoot)
          .filter((root): root is string => Boolean(root)),
      ),
    ]
    const discovered = await Promise.all(
      roots.map(async (root) => {
        try {
          const canonical = await realpath(root)
          return (await stat(canonical)).isDirectory() ? canonical : null
        } catch {
          return null
        }
      }),
    )
    const recentProjects = [
      ...new Set([
        ...current().recentProjects,
        ...discovered.filter((root): root is string => root !== null),
      ]),
    ].slice(0, 30)
    if (recentProjects.length !== current().recentProjects.length)
      await savePreferences({ recentProjects })
    return result
  })

  method('create', async (project, modelId, options) => {
    const root = await knownProject(project)
    await trustProject(root)
    const { worktree } =
      z.object({ worktree: z.boolean().optional() }).optional().parse(options) ?? {}
    return muse.create(root, z.string().optional().parse(modelId), { worktree })
  })

  method('open', async (value) => {
    const view = await muse.open(id.parse(value))
    // Record a worktree session's parent project, not each worktree folder.
    const root = view.session.workspaceRoot && projectRoot(view.session.workspaceRoot)
    if (root && !current().recentProjects.includes(root))
      await savePreferences({ recentProjects: [root, ...current().recentProjects].slice(0, 30) })
    return view
  })

  method('send', async (value) => {
    // Text only. Attachments come with the attachment methods in M4.
    const input = z
      .object({
```

```ts
console.dir = (value: unknown) => console.error(value)

let stdoutBroken = false
let quitting = false

function emit(event: AppEvent) {
  publish(event)
  wire.emit(event)
}
const muse = new MuseHost(emit)
const backend = createBackend({
  muse,
  ask: (value) => wire.ask(value),
  emit,
  version,
  quitting: () => quitting,
  // Run the quit path after the current Reply is written, so mMac reads it.
  quit: (code) => setImmediate(() => void quit(code)),
})
const wire = new Wire((line) => {
  if (!stdoutBroken) writeOut(line)
}, backend.methods)

/** Waits for every queued stdout write, then exits. */
function exit(code: number) {
  if (stdoutBroken) process.exit(code)
  // A stdout that breaks while this write waits may never call back. Do not hang on it.
  setTimeout(() => process.exit(code), 2000).unref()
  process.stdout.write('', () => process.exit(code))
}

async function quit(code: number) {
  if (quitting) return
  quitting = true
  wire.cancelAsks()
  const failed = (error: unknown) => {
    console.error(`The mMac backend did not shut down cleanly: ${messageOf(error)}`)
    code ||= 1
  }
  // Closing Muse makes waiting requests fail, so drain() cannot wait forever.
  const results = await Promise.allSettled([muse.close(), backend.preferenceWrites(), wire.drain()])
  for (const result of results) if (result.status === 'rejected') failed(result.reason)
  try {
    // A connect that was in progress during the first close has finished by now,
    // and only then does MuseHost hold a host to close.
    await muse.close()
  } catch (error) {
    failed(error)
  }
  exit(code)
}

const lines = createInterface({ input: process.stdin, crlfDelay: Infinity })
lines.on('line', (line) => {
  if (!quitting) void wire.receive(line)
})
// mMac closed stdin, quit or crashed.
lines.on('close', () => void quit(0))
process.on('SIGTERM', () => void quit(0))
process.stdout.on('error', () => {
  stdoutBroken = true
  void quit(0)
```

```swift
import Foundation
import MuseBackend

/// A fake backend. Each line mMac sends goes to `script`, which returns the lines to answer with.
public final class ScriptedBackend: Transport, @unchecked Sendable {
  public let lines: AsyncStream<Data>
  private let continuation: AsyncStream<Data>.Continuation
  private let script: @Sendable ([String: JSONValue]) -> [String]
  private let lock = NSLock()
  private var received: [[String: JSONValue]] = []
  private var stopped = false

  public init(script: @escaping @Sendable ([String: JSONValue]) -> [String] = { _ in [] }) {
    let stream = AsyncStream.makeStream(of: Data.self)
    lines = stream.stream
    continuation = stream.continuation
    self.script = script
  }

  /// Every message mMac sent, decoded. A message is recorded after its replies are pushed,
  /// so a test that sees it can rely on them being on their way.
  public var messages: [[String: JSONValue]] { lock.withLock { received } }
  public var forceStopped: Bool { lock.withLock { stopped } }

  public func send(_ line: Data) throws {
    let message = try JSONDecoder().decode([String: JSONValue].self, from: line)
    for reply in script(message) { push(reply) }
    lock.withLock { received.append(message) }
  }

  /// Sends one line to mMac, as the backend would.
  public func push(_ line: String) { continuation.yield(Data(line.utf8)) }

  /// Ends the stream, as the backend does when it exits.
  public func close() { continuation.finish() }

  public func forceStop() {
    lock.withLock { stopped = true }
    continuation.finish()
  }
}
```

```swift
  /// Sends a Request and returns the Reply's value. If the calling task is cancelled, this throws
  /// `CancellationError` at once and ignores the Reply when it comes. The backend still finishes
  /// the request; cancelling only stops waiting.
  public func request(_ method: String, _ args: [JSONValue] = []) async throws -> JSONValue {
    if stopped { throw BackendError.stopped }
    try Task.checkCancellation()
    let id = nextId
    nextId += 1
    let line = try JSONEncoder().encode(OutgoingRequest(id: id, method: method, args: args))
    return try await withTaskCancellationHandler {
      try await withCheckedThrowingContinuation { continuation in
        // Cancelled between the check above and here: the handler found nothing to cancel.
        if Task.isCancelled {
          continuation.resume(throwing: CancellationError())
          return
        }
        pending[id] = continuation
        do {
          try transport.send(line)
        } catch {
          pending.removeValue(forKey: id)
          continuation.resume(throwing: BackendError.stopped)
        }
      }
    } onCancel: {
      Task { await self.abandon(id) }
    }
  }

  /// Stops waiting for a request whose caller was cancelled.
  private func abandon(_ id: Int) {
    pending.removeValue(forKey: id)?.resume(throwing: CancellationError())
  }

  /// Stops the backend at once. Used when a second Quit finds it never answered `shutdown`.
```

```swift
import Foundation
import Markdown

/// One task-list or plain list item.
public struct MarkdownListItem: Equatable, Sendable {
  /// `true` or `false` for a task-list item (`- [x]`), nil for a plain item.
  public let checked: Bool?
  public let blocks: [MarkdownBlock]
}

/// Markdown as blocks of attributed text, ready for SwiftUI. Inline styles travel as
/// `inlinePresentationIntent` and links as `.link`, which SwiftUI's `Text` draws.
public enum MarkdownBlock: Equatable, Sendable {
  case heading(level: Int, text: AttributedString)
  case paragraph(AttributedString)
  /// The code without its final newline. `language` is nil when the fence names none.
  case code(language: String?, code: String)
  case quote([MarkdownBlock])
  case list(ordered: Bool, start: Int, items: [MarkdownListItem])
  case table(header: [AttributedString], rows: [[AttributedString]])
  case rule

  /// Parses GitHub-flavoured Markdown, as Electron's react-markdown with remark-gfm does.
  public static func parse(_ source: String) -> [MarkdownBlock] {
    blocks(in: Document(parsing: source))
  }

  static func blocks(in container: Markup) -> [MarkdownBlock] {
    container.children.compactMap(block)
  }

  static func block(_ markup: Markup) -> MarkdownBlock? {
    if let heading = markup as? Heading { return .heading(level: heading.level, text: inline(heading)) }
    if let paragraph = markup as? Paragraph { return .paragraph(inline(paragraph)) }
    if let code = markup as? CodeBlock {
      let language = code.language?.trimmingCharacters(in: .whitespaces)
      let text = code.code.hasSuffix("\n") ? String(code.code.dropLast()) : code.code
      return .code(language: language?.isEmpty == false ? language : nil, code: text)
    }
    if let quote = markup as? BlockQuote { return .quote(blocks(in: quote)) }
    if let list = markup as? OrderedList {
      return .list(ordered: true, start: Int(list.startIndex), items: list.listItems.map(item))
    }
    if let list = markup as? UnorderedList {
      return .list(ordered: false, start: 1, items: list.listItems.map(item))
    }
    if let table = markup as? Table {
      return .table(
        header: table.head.cells.map { inline($0) },
        rows: table.body.rows.map { row in row.cells.map { inline($0) } })
    }
    if markup is ThematicBreak { return .rule }
    if let html = markup as? HTMLBlock {
      return .paragraph(AttributedString(html.rawHTML.trimmingCharacters(in: .newlines)))
    }
    return nil
  }

  static func item(_ item: ListItem) -> MarkdownListItem {
    let checked: Bool? =
      switch item.checkbox {
      case .checked: true
      case .unchecked: false
      case nil: nil
      }
    return MarkdownListItem(checked: checked, blocks: blocks(in: item))
  }

  /// The inline children of `markup` as one attributed string.
  static func inline(_ markup: Markup, intent: InlinePresentationIntent = [], link: URL? = nil)
    -> AttributedString
  {
    var result = AttributedString()
    for child in markup.children {
      if let text = child as? Markdown.Text {
        result += styled(text.string, intent, link)
      } else if let code = child as? InlineCode {
        result += styled(code.code, intent.union(.code), link)
      } else if child is Emphasis {
        result += inline(child, intent: intent.union(.emphasized), link: link)
      } else if child is Strong {
        result += inline(child, intent: intent.union(.stronglyEmphasized), link: link)
      } else if child is Strikethrough {
        result += inline(child, intent: intent.union(.strikethrough), link: link)
      } else if let anchor = child as? Link {
        result += inline(child, intent: intent, link: webURL(anchor.destination) ?? link)
      } else if let image = child as? Image {
        let alt = image.plainText.isEmpty ? "External image" : image.plainText
        result += styled("[Image: \(alt)]", intent, link)
      } else if child is SoftBreak {
        result += styled(" ", intent, link)
      } else if child is LineBreak {
        result += styled("\n", intent, link)
      } else if let html = child as? InlineHTML {
        result += styled(html.rawHTML, intent, link)
      } else {
        result += inline(child, intent: intent, link: link)
      }
    }
    return result
  }

  static func styled(_ string: String, _ intent: InlinePresentationIntent, _ link: URL?)
    -> AttributedString
  {
    var text = AttributedString(string)
    if !intent.isEmpty { text.inlinePresentationIntent = intent }
    if let link { text.link = link }
    return text
  }

  /// Only web links open, as in Electron.
  static func webURL(_ destination: String?) -> URL? {
    guard let destination, let url = URL(string: destination),
      ["http", "https"].contains(url.scheme?.lowercased())
    else { return nil }
    return url
  }
}

/// Parsed Markdown per transcript item, so a streamed update re-parses only the item that changed.
@MainActor
public final class MarkdownCache {
  public static let shared = MarkdownCache()

  struct Key: Hashable {
    let id: String
    let text: String
  }

  private var entries: [Key: [MarkdownBlock]] = [:]
  private var order: [Key] = []
  private let limit = 400
  /// How many times `blocks(id:text:)` parsed. Tests read it.
  private(set) var parseCount = 0

  public init() {}

  public func blocks(id: String, text: String) -> [MarkdownBlock] {
    let key = Key(id: id, text: text)
    if let cached = entries[key] { return cached }
    let parsed = MarkdownBlock.parse(text)
    parseCount += 1
    entries[key] = parsed
    order.append(key)
    if order.count > limit { entries[order.removeFirst()] = nil }
    return parsed
  }
}
```

```swift
/// One row of the transcript. Electron's rules are in `src/renderer/src/components/Transcript.tsx`.
public enum TranscriptEntry: Identifiable, Equatable, Sendable {
  case user(TranscriptItem)
  case agent(TranscriptItem)
  case reasoning(TranscriptItem)
  case tool(TranscriptItem)
  /// Three or more completed tools in a row.
  case toolGroup([TranscriptItem])

  public var id: String {
    switch self {
    case .user(let item), .agent(let item), .reasoning(let item), .tool(let item): item.itemId
    case .toolGroup(let items): "group-\(items[0].itemId)"
    }
  }

  public static func build(_ items: [TranscriptItem]) -> [TranscriptEntry] {
    var entries: [TranscriptEntry] = []
    var run: [TranscriptItem] = []
    func flush() {
      if run.count >= 3 { entries.append(.toolGroup(run)) } else { entries += run.map(TranscriptEntry.tool) }
      run = []
    }
    for item in items where item.retracted != true && !Activity.isInternal(item) {
      switch item.kind {
      case "userMessage":
        flush()
        entries.append(.user(item))
      case "agentMessage":
        flush()
        entries.append(.agent(item))
      case "reasoning":
        flush()
        entries.append(.reasoning(item))
      default:
        if item.status == "completed" {
          run.append(item)
        } else {
          flush()
          entries.append(.tool(item))
        }
      }
    }
    flush()
    return entries
  }
}

/// Background work that shows only in the Activity inspector (M2), never in the transcript.
public enum Activity {
  public static func isInternal(_ item: TranscriptItem) -> Bool {
    item.kind == "reminderChild" || item.kind == "hookRun"
  }

  /// True when something runs and all of it is internal: "Finishing background tasks…".
  public static func isBackgroundOnly(_ items: [TranscriptItem]) -> Bool {
    let active = items.filter { $0.retracted != true && $0.status == "inProgress" }
    return !active.isEmpty && active.allSatisfy(isInternal)
  }
}

/// The labels of transcript rows. JavaScript's `a || b` skips empty strings, so `first` does too.
public enum ToolPresentation {
  static func first(_ values: String?...) -> String? {
    values.first { $0?.isEmpty == false } ?? nil
  }

  /// `toolCall` becomes `tool call`.
  static func spaced(_ kind: String) -> String {
    kind.reduce(into: "") { text, character in
      if character.isUppercase { text += " " + character.lowercased() } else { text.append(character) }
    }
  }

  public static func title(_ item: TranscriptItem) -> String {
    first(item.tool, item.label, item.role) ?? spaced(item.kind)
  }

  public static func summary(_ item: TranscriptItem) -> String? {
    first(item.statusLine, item.objective, item.commandText, item.fallbackText)
  }

  /// `stored` is the full output read with "Read stored output", when there is one.
  public static func output(_ item: TranscriptItem, stored: String?) -> String? {
    first(stored, item.visibleOutput, item.result?.text, item.failureReason, item.finalSummary)
  }

  public static func formattedArgs(_ args: String) -> String {
    guard let data = args.data(using: .utf8),
      let object = try? JSONSerialization.jsonObject(with: data, options: [.fragmentsAllowed]),
      let pretty = try? JSONSerialization.data(
        withJSONObject: object, options: [.prettyPrinted, .sortedKeys, .fragmentsAllowed])
    else { return args }
    return String(decoding: pretty, as: UTF8.self)
  }

  /// `+3 −1`, with the minus sign U+2212, or nil when nothing changed.
  public static func patch(_ item: TranscriptItem) -> String? {
    guard let patch = item.patchSummary, patch.added > 0 || patch.removed > 0 else { return nil }
    return "+\(patch.added) \u{2212}\(patch.removed)"
  }

  public static func footer(_ item: TranscriptItem) -> String {
    guard let duration = item.durationMs else { return item.status }
    return "\(item.status) · \(String(format: "%.1f", duration / 1000))s"
  }

  public static func groupTitle(_ items: [TranscriptItem]) -> String { "Ran \(items.count) tools" }

  public static func groupDetail(_ items: [TranscriptItem]) -> String {
    var titles: [String] = []
    for item in items where !titles.contains(title(item)) { titles.append(title(item)) }
    return titles.prefix(3).joined(separator: ", ")
  }

  public static func groupPatch(_ items: [TranscriptItem]) -> String? {
    let added = items.compactMap(\.patchSummary?.added).reduce(0, +)
    let removed = items.compactMap(\.patchSummary?.removed).reduce(0, +)
    return added > 0 || removed > 0 ? "+\(added) \u{2212}\(removed)" : nil
  }

  /// A user message as plain text, with injected tags removed.
  public static func messageText(_ item: TranscriptItem) -> String {
    first(SessionTitle.stripInjectedTags(first(item.displayText, item.text)), item.displayText, item.text) ?? ""
  }

  public static func reasoningText(_ item: TranscriptItem) -> String {
    first((item.summary ?? []).joined(separator: "\n\n"), item.text)
      ?? "No reasoning text was provided by the model."
  }
}
```

```swift
/// Conversation titles, as Electron's `sessionTitle` in `Primitives.tsx`.
public enum SessionTitle {
  public static func text(name: String?, title: String?, firstUserPrompt: String?) -> String {
    let raw = [name, title, firstUserPrompt].lazy.map(clean).first { !$0.isEmpty } ?? ""
    guard !raw.isEmpty else { return "Untitled conversation" }
    guard raw.count > 76 else { return raw }
    return String(raw.prefix(76)).trimmingCharacters(in: .whitespaces) + "…"
  }

  public static func of(_ session: Session) -> String {
    text(name: session.name, title: session.title, firstUserPrompt: session.firstUserPrompt)
  }

  /// Removes injected tags and collapses whitespace.
  static func clean(_ value: String?) -> String {
    stripInjectedTags(value)
      .replacingOccurrences(of: #"\s+"#, with: " ", options: .regularExpression)
      .trimmingCharacters(in: .whitespacesAndNewlines)
  }

  /// Removes `<tag …>…</tag>` blocks that tools inject, as Electron's `stripInjectedTags`.
  static func stripInjectedTags(_ value: String?) -> String {
    guard var text = value, !text.isEmpty else { return "" }
    let block = try! NSRegularExpression(pattern: #"<([a-zA-Z_][\w.-]*)\b[^>]*>[\s\S]*?</\1>"#)
    for _ in 0..<4 {
      let next = block.stringByReplacingMatches(
        in: text, range: NSRange(text.startIndex..., in: text), withTemplate: "")
      if next == text { break }
      text = next
    }
    if let closing = text.range(of: "</", options: .backwards),
      let end = text[closing.lowerBound...].firstIndex(of: ">"),
      text[closing.lowerBound...end].range(of: #"^</[a-zA-Z_][\w.-]*>$"#, options: .regularExpression) != nil
    {
      text = String(text[text.index(after: end)...])
    }
    if let opening = text.range(of: #"^<[a-zA-Z_][\w.-]*\b[^>]*>[\s\S]*"#, options: [.regularExpression, .caseInsensitive]) {
      text.removeSubrange(opening)
    }
    return text.trimmingCharacters(in: .whitespacesAndNewlines)
  }
}

/// The conversation list, as Electron's `App.tsx` builds it (pinning and archiving arrive in M4).
public enum SidebarSections {
  public static func build(
    _ sessions: [Session], project: String, now: Date, calendar: Calendar = .current
  ) -> [SidebarSection] {
    let root = project.isEmpty ? nil : ProjectPath.root(of: project)
    let shown = sessions
      .filter { $0.kind != "subagent" && $0.kind != "reminder" }
      .filter { session in
        guard let root else { return true }
        return session.workspaceRoot.map(ProjectPath.root(of:)) == root
      }
      .sorted { ($0.lastActivityAt ?? $0.updatedAt) > ($1.lastActivityAt ?? $1.updatedAt) }
    var sections: [SidebarSection] = []
    for session in shown {
      let title = group(session, now: now, calendar: calendar)
      if sections.last?.title == title {
        sections[sections.count - 1] = SidebarSection(title: title, sessions: sections[sections.count - 1].sessions + [session])
      } else {
        sections.append(SidebarSection(title: title, sessions: [session]))
      }
    }
    return sections
  }

  static func group(_ session: Session, now: Date, calendar: Calendar) -> String {
    guard let date = RelativeTime.date(session.lastActivityAt ?? session.updatedAt) else { return "Earlier" }
    let today = calendar.startOfDay(for: now)
    if date >= today { return "Today" }
    if let yesterday = calendar.date(byAdding: .day, value: -1, to: today), date >= yesterday { return "Yesterday" }
    if let week = calendar.date(byAdding: .day, value: -7, to: today), date >= week { return "Previous 7 days" }
    return "Earlier"
  }
}

/// Electron's `friendlyTime`: Now, minutes, hours, then a short date.
public enum RelativeTime {
  public static func text(_ value: String, now: Date = .now, locale: Locale = .current) -> String {
    guard let date = date(value) else { return "" }
    let minutes = now.timeIntervalSince(date) / 60
    if minutes < 1 { return "Now" }
    if minutes < 60 { return "\(Int(minutes))m" }
    if minutes < 1440 { return "\(Int(minutes / 60))h" }
    return date.formatted(.dateTime.month(.abbreviated).day().locale(locale))
  }

  /// Parses a CLI timestamp: ISO 8601, with or without fractional seconds.
  public static func date(_ value: String) -> Date? {
    let precise = ISO8601DateFormatter()
    precise.formatOptions = [.withInternetDateTime, .withFractionalSeconds]
    return precise.date(from: value) ?? ISO8601DateFormatter().date(from: value)
  }
}
```

```swift
import Foundation

/// The answers being written for one Muse question, as Electron's `QuestionCard`.
public struct QuestionForm: Equatable, Sendable {
  public let question: UserQuestion
  private var answers: [String: QuestionAnswer] = [:]

  public init(_ question: UserQuestion) { self.question = question }

  func prompt(_ id: String) -> UserQuestion.Prompt? { question.questions.first { $0.id == id } }

  /// Chooses or toggles an option. Choosing clears any free text for that prompt.
  public mutating func choose(_ label: String, in promptId: String) {
    guard let prompt = prompt(promptId) else { return }
    if prompt.selection.mode == "multiple" {
      var labels = answers[promptId]?.selectedLabels ?? []
      if let index = labels.firstIndex(of: label) { labels.remove(at: index) } else { labels.append(label) }
      answers[promptId] = QuestionAnswer(questionId: promptId, selectedLabels: labels)
    } else {
      answers[promptId] = QuestionAnswer(questionId: promptId, selectedLabel: label)
    }
  }

  /// Writes free text, up to 500 characters. Writing clears any selection for that prompt.
  public mutating func write(_ text: String, in promptId: String) {
    answers[promptId] = QuestionAnswer(questionId: promptId, freeText: String(text.prefix(500)))
  }

  public func isChosen(_ label: String, in promptId: String) -> Bool {
    let answer = answers[promptId]
    return answer?.selectedLabel == label || answer?.selectedLabels?.contains(label) == true
  }

  public func freeText(in promptId: String) -> String { answers[promptId]?.freeText ?? "" }

  /// Every prompt has free text, a single choice, or a number of choices within its limits.
  public var canContinue: Bool {
    question.questions.allSatisfy { prompt in
      guard let answer = answers[prompt.id] else { return false }
      if answer.freeText?.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty == false { return true }
      if answer.selectedLabel != nil { return true }
      guard prompt.selection.mode == "multiple", let labels = answer.selectedLabels else { return false }
      return labels.count >= (prompt.selection.minSelections ?? 1)
        && labels.count <= (prompt.selection.maxSelections ?? Int.max)
    }
  }

  /// The answers in prompt order. Free text is sent untrimmed, as Electron does.
  public var submission: [QuestionAnswer] { question.questions.compactMap { answers[$0.id] } }
}
```

```swift
    guard let method = message["method"] else { return nil }
    return [method, message["args"] ?? .null]
  }
}

/// Waits up to a second for `condition`.
@MainActor
func eventually(_ condition: () -> Bool) async throws {
  for _ in 0..<200 {
    if condition() { return }
    try await Task.sleep(for: .milliseconds(5))

  Issue.record("Timed out waiting for a condition")
```

```swift
import Foundation
import MuseBackend
import Observation

/// An error mMac writes itself, as opposed to one the backend sends.
public struct WorkspaceError: LocalizedError, Equatable, Sendable {
  public let errorDescription: String?
  public init(_ message: String) { errorDescription = message }
}

/// The conversation state of the mMac window: the connection, Muse history, the project filter,
/// the open conversation and the composer. Every change goes through the backend; this keeps what
/// the views draw. Electron keeps the same state in `src/renderer/src/App.tsx`.
@MainActor @Observable
public final class Workspace {
  public enum SendOutcome: Equatable, Sendable {
    case sent
    /// No conversation is open and no project is chosen. Show the project panel, then send again.
    case needsProject
    case notSent
  }

  public private(set) var status: ConnectionStatus
  public internal(set) var preferences: Preferences
  public private(set) var sessions: [Session] = []
  public private(set) var historyLoading = false
  public private(set) var historyError: String?
  /// The project filter, and the folder a new conversation starts in. Empty means all projects.
  public private(set) var project: String
  public internal(set) var view: SessionView?
  /// The conversation being opened, for a spinner.
  public private(set) var openingSessionId: String?
  public internal(set) var models: [MuseModel] = []
  /// The model for a new conversation, or the open conversation's model. Empty is the CLI default.
  public internal(set) var modelId = ""
  public var mode: SendMode = .queue
  public internal(set) var submitting = false
  public var errorMessage: String?
  public internal(set) var decidingApprovals: Set<String> = []
  public internal(set) var answeringQuestions: Set<String> = []
  public internal(set) var storedOutput: [String: String] = [:]
  public internal(set) var loadingOutput: Set<String> = []

  let client: BackendClient
  var drafts: [String: String] = [:]
  private var openSequence = 0
  private var refreshSequence = 0
  private var refreshDelay: Task<Void, Never>?
  /// The pause before a `sessions-changed` event refreshes history. Electron waits 250 ms.
  private let refreshDebounce: Duration

  public init(
    client: BackendClient, started: Started, refreshDebounce: Duration = .milliseconds(250)
  ) {
    self.client = client
    status = started.status
    preferences = started.preferences
    project = started.preferences.recentProjects.first ?? ""
    self.refreshDebounce = refreshDebounce
  }

  public var sections: [SidebarSection] {
    SidebarSections.build(sessions, project: project, now: .now)
  }
  public var isConnected: Bool { status.isReady }
  public var isRunning: Bool { view?.session.status == "running" }
  public var effort: String { preferences.reasoningEffort }

  /// The composer text for the open conversation, or for a new one in the current project.
  /// Drafts live in memory only, as in Electron.
  public var draft: String {
    get { drafts[draftKey] ?? "" }
    set { drafts[draftKey] = newValue }
  }
  var draftKey: String { view?.session.sessionId ?? "new:\(project)" }

  /// Loads history and models. Call it once `start` has replied; a later `ready` event calls it again.
  public func begin() async {
    guard status.isReady else { return }
    await refreshSessions()
    await loadModels()
  }

  public func apply(_ event: AppEvent) {
    switch event {
    case .connection(let next):
      let becameReady = !status.isReady && next.isReady
      status = next
      if becameReady { Task { await begin() } }
    case .preferences(let next):
      preferences = next
    case .session(let next):
      if next.session.sessionId == view?.session.sessionId { view = next }
      if let index = sessions.firstIndex(where: { $0.sessionId == next.session.sessionId }) {
        sessions[index] = next.session
      }
    case .sessionsChanged:
      refreshDelay?.cancel()
      refreshDelay = Task { [refreshDebounce] in
        try? await Task.sleep(for: refreshDebounce)
        guard !Task.isCancelled else { return }
        await self.refreshSessions()
      }
    case .error(let message):
      errorMessage = message
    case .other:
      break
    }
  }

  /// Loads every page of Muse history. A newer refresh makes an older one stop.
  public func refreshSessions() async {
    refreshSequence += 1
    let sequence = refreshSequence
    if sessions.isEmpty { historyLoading = true }
    defer { if sequence == refreshSequence { historyLoading = false } }
    let known = Dictionary(sessions.map { ($0.sessionId, $0) }, uniquingKeysWith: { first, _ in first })
    var merged: [String: Session] = [:]
    var order: [String] = []
    var cursor: String?
    var seen = Set<String>()
    do {
      repeat {
        let page = try await client.sessions(cursor: cursor)
        guard sequence == refreshSequence else { return }
        for session in page.sessions {
          if merged[session.sessionId] == nil { order.append(session.sessionId) }
          merged[session.sessionId] = Self.keepingKnownName(session, from: known)
        }
        sessions = order.compactMap { merged[$0] }
        cursor = page.nextCursor
        if let cursor, !seen.insert(cursor).inserted {
          throw WorkspaceError("Muse returned a repeated history cursor. Reconnect to refresh history.")
        }
      } while cursor != nil
      historyError = nil
    } catch {
      if sequence == refreshSequence { historyError = error.localizedDescription }
    }
  }

  /// `session/list` can lag a rename for a live conversation and leave out its name. Keep the name
  /// a session event or `open` already gave. The CLI itself lowercases ASCII letters in names.
  static func keepingKnownName(_ session: Session, from known: [String: Session]) -> Session {
    guard session.name == nil, let name = known[session.sessionId]?.name else { return session }
    var kept = session
    kept.name = name
    return kept
  }

  /// Shows a recent project, or all projects for an empty path, and starts a new conversation.
  public func selectProject(_ path: String) {
    project = path
    startNew()
  }

  /// Closes the open conversation, so the composer starts a new one.
  public func startNew() {
    view = nil
    mode = .queue
  }

  /// Adds a folder chosen in the open panel and selects its real path.
  @discardableResult
  public func addProject(_ folder: URL) async -> Bool {
    do {
      selectProject(try await client.addProject(folder))
      return true
    } catch {
      errorMessage = error.localizedDescription
      return false
    }
  }

  /// Opens a conversation. A reply that arrives after a newer `open` started is ignored.
  /// `force` reopens the open conversation, after a reconnect.
  public func open(_ sessionId: String, force: Bool = false) async {
    guard force || sessionId != view?.session.sessionId else { return }
    openSequence += 1
    let sequence = openSequence
    openingSessionId = sessionId
    defer { if sequence == openSequence { openingSessionId = nil } }
    do {
      let opened = try await client.open(sessionId)
      guard sequence == openSequence else { return }
      view = opened
      if let root = opened.session.workspaceRoot { project = root }
      modelId = opened.session.modelId ?? ""
    } catch {
      guard sequence == openSequence else { return }
      errorMessage = error.localizedDescription
    }
  }

  /// Loads the models Muse offers. A new conversation starts on the default one, as in Electron.
  public func loadModels() async {
    do {
      models = try await client.models()
      if modelId.isEmpty { modelId = models.first(where: \.isDefault)?.modelId ?? "" }
    } catch {
      errorMessage = error.localizedDescription
    }
  }

  /// Runs one backend call and shows its error, if any.
  func run(_ work: () async throws -> Void) async {
    do { try await work() } catch { errorMessage = error.localizedDescription }
  }
}
```

```swift
import Foundation
import MuseBackend

// What the composer, the toolbar and the cards do. Electron's versions are in
// src/renderer/src/App.tsx (submit, changeModel, rename) and Transcript.tsx (the cards).
extension Workspace {
  /// Sends the draft. With no conversation open, it creates one in the current project first.
  public func send() async -> SendOutcome {
    let text = draft
    guard !text.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty, !submitting else {
      return .notSent
    }
    if view == nil, project.isEmpty { return .needsProject }
    submitting = true
    defer { submitting = false }
    let startKey = draftKey
    var shownId: String?
    var previousStatus: String?
    do {
      if view == nil {
        view = try await client.create(project: project, modelId: modelId.isEmpty ? nil : modelId)
      }
      guard let sessionId = view?.session.sessionId else { return .notSent }
      // Show the message at once. The next session event replaces the whole list.
      if view?.items.contains(where: { $0.kind == "userMessage" && ($0.displayText ?? $0.text) == text }) != true {
        let id = "optimistic-\(UUID().uuidString)"
        shownId = id
        view?.items.append(
          TranscriptItem(itemId: id, kind: "userMessage", status: "completed", text: text, displayText: text))
      }
      previousStatus = view?.session.status
      view?.session.status = "running"
      // Clear the draft only where it still holds what was sent.
      for key in [startKey, sessionId] where drafts[key] == text { drafts[key] = nil }
      try await client.send(sessionId: sessionId, text: text, effort: effort, mode: mode)
      return .sent
    } catch {
      if let shownId { view?.items.removeAll { $0.itemId == shownId } }
      if let previousStatus { view?.session.status = previousStatus }
      if draft.isEmpty { draft = text }
      errorMessage = error.localizedDescription
      return .notSent
    }
  }

  /// Stops the open conversation's turn.
  public func stop() async {
    guard let sessionId = view?.session.sessionId else { return }
    await run { try await self.client.cancel(sessionId) }
  }

  /// Renames the open conversation. Returns false for a blank name or a failure.
  public func rename(_ name: String) async -> Bool {
    let trimmed = name.trimmingCharacters(in: .whitespacesAndNewlines)
    guard let sessionId = view?.session.sessionId, !trimmed.isEmpty else { return false }
    do {
      try await client.rename(sessionId: sessionId, name: trimmed)
      return true
    } catch {
      errorMessage = error.localizedDescription
      return false
    }
  }

  /// Chooses the model: for the next new conversation, or for the open one through the backend.
  public func chooseModel(_ id: String) async {
    guard let sessionId = view?.session.sessionId else {
      modelId = id
      return
    }
    await run {
      try await self.client.setModel(sessionId: sessionId, modelId: id)
      self.modelId = id
    }
  }

  /// Saves the reasoning effort, which every later message uses.
  public func chooseEffort(_ effort: String) async {
    await run { self.preferences = try await self.client.preferences(PreferencesPatch(reasoningEffort: effort)) }
  }

  /// Saves a custom Muse Code path (empty for automatic detection), then reconnects.
  public func setCLIPath(_ path: String) async {
    do {
      preferences = try await client.preferences(PreferencesPatch(cliPath: path))
    } catch {
      errorMessage = error.localizedDescription
      return
    }
    await reconnect()
  }

  /// Reconnects to Muse, then reopens the open conversation, as Electron does.
  public func reconnect() async {
    do {
      let next = try await client.connect()
      apply(.connection(next))
      if next.isReady, let sessionId = view?.session.sessionId { await open(sessionId, force: true) }
    } catch {
      errorMessage = error.localizedDescription
    }
  }

  public func approve(_ approval: Approval, choice: Approval.Choice) async {
    decidingApprovals.insert(approval.approvalId)
    defer { decidingApprovals.remove(approval.approvalId) }
    await run {
      try await self.client.approve(
        sessionId: approval.sessionId, approvalId: approval.approvalId, choiceId: choice.choiceId)
    }
  }

  public func answer(_ question: UserQuestion, answers: [QuestionAnswer]) async {
    answeringQuestions.insert(question.userInputId)
    defer { answeringQuestions.remove(question.userInputId) }
    await run {
      try await self.client.answer(
        sessionId: question.sessionId, userInputId: question.userInputId, answers: answers)
    }
  }

  /// "Skip question": cancels the question, and Muse continues without an answer.
  public func skip(_ question: UserQuestion) async {
    answeringQuestions.insert(question.userInputId)
    defer { answeringQuestions.remove(question.userInputId) }
    await run {
      try await self.client.cancelQuestion(sessionId: question.sessionId, userInputId: question.userInputId)
    }
  }

  /// "Read stored output": reads a tool item's full output once.
  public func readOutput(_ item: TranscriptItem) async {
    guard let sessionId = view?.session.sessionId, storedOutput[item.itemId] == nil,
      !loadingOutput.contains(item.itemId)
    else { return }
    loadingOutput.insert(item.itemId)
    defer { loadingOutput.remove(item.itemId) }
    await run {
      self.storedOutput[item.itemId] = try await self.client.readOutput(sessionId: sessionId, itemId: item.itemId)
    }
  }
}
```

```swift
import AppKit
import MuseBackend

/// Starts and stops the backend, and owns what lives as long as it does: the Workspace, the Ask
/// queue, and the error output shown when the backend fails.
@MainActor @Observable
final class AppController {
  enum Phase: Equatable {
    case starting
    case running
    /// The backend could not start. `details` is its last stderr output.
    case setupFailed(message: String, details: String)
    /// The backend ended while mMac was running.
    case stopped(message: String, details: String)
  }

  private(set) var phase: Phase = .starting
  private(set) var workspace: Workspace?
  let asks = AskQueue()
  private var client: BackendClient?
  private var transport: ProcessTransport?
  private var launching = false
  private var quitting = false

  /// Starts a backend. Does nothing while one is starting or running.
  func start() async {
    guard client == nil, !launching else { return }
    launching = true
    defer { launching = false }
    phase = .starting
    workspace = nil
    var launched: ProcessTransport?
    do {
      let repository = try Self.repository()
      let arguments = Self.backendArguments()
      let transport = try await Task.detached {
        try Launcher.launch(repository: repository, arguments: arguments)
      }.value
      launched = transport
      self.transport = transport
      let asks = self.asks
      let client = BackendClient(transport: transport, answerAsk: { ask in await asks.present(ask) })
      self.client = client
      await client.run()
      Task {
        for await event in client.events where self.client === client {
          self.workspace?.apply(event)
        }
        self.backendStopped(client)
      }
      _ = try await client.hello()
      let started = try await client.start(dataFolder: Self.dataFolder())
      let workspace = Workspace(client: client, started: started)
      self.workspace = workspace
      phase = .running
      await workspace.begin()
    } catch {
      // A backend that failed to start is dropped, and its input closed so it quits.
      let details = launched?.recentErrorOutput ?? ""
      client = nil
      transport = nil
      launched?.close()
      asks.cancelAll()
      phase = .setupFailed(message: error.localizedDescription, details: details)
    }
  }

  /// Returns true when mMac may quit. The backend may Ask first if a turn is running.
  func quit() async -> Bool {
    guard let client, phase == .running else { return true }
    quitting = true
    do {
      let quit = try await client.shutdown()
      if !quit { quitting = false }
      return quit
    } catch {
      return true
    }
  }

  /// A second Quit while the first waits: stop the backend now, so the first Quit's wait ends.
  func forceQuit() {
    asks.cancelAll()
    client?.forceStop()
  }

  private func backendStopped(_ stopped: BackendClient) {
    asks.cancelAll()
    guard client === stopped, !quitting else { return }
    let details = transport?.recentErrorOutput ?? ""
    client = nil
    transport = nil
    workspace = nil
    phase = .stopped(
      message: "The backend process ended. Restart it to continue. Your conversations are saved in Muse Code.",
      details: details)
  }

  // MARK: Panels

  /// "Open project…": adds the chosen folder and selects it.
  func openProject() async {
    guard let workspace, let folder = Self.chooseProjectFolder() else { return }
    await workspace.addProject(folder)
  }

  /// Sends the draft. With no project yet, asks for one first, as Electron does.
  /// `send(addingProject:)` moves the draft to the new project's key, so no copy is left behind.
  func send() async {
    guard let workspace else { return }
    guard await workspace.send() == .needsProject, let folder = Self.chooseProjectFolder() else { return }
    _ = await workspace.send(addingProject: folder)
  }

  /// "Choose Muse Code…": saves the executable's path and reconnects.
  func chooseCLI() async {
    guard let workspace else { return }
    let panel = NSOpenPanel()
    panel.title = "Choose the Muse Code executable"
    panel.canChooseFiles = true
    panel.canChooseDirectories = false
    panel.showsHiddenFiles = true
    guard panel.runModal() == .OK, let url = panel.url else { return }
    await workspace.setCLIPath(url.path)
  }

  /// "Choose checkout…": runs the backend from another Muse Desktop checkout.
  func chooseRepository() async {
    let panel = NSOpenPanel()
    panel.message = "Choose the folder that holds your Muse Desktop checkout."
    panel.prompt = "Use this checkout"
    panel.canChooseFiles = false
    panel.canChooseDirectories = true
    guard panel.runModal() == .OK, let url = panel.url else { return }
    UserDefaults.standard.set(url.path, forKey: Self.repositoryKey)
    await start()
  }

  // MARK: Where things are

  static let repositoryKey = "MMacRepository"

  private struct SetupError: LocalizedError {
    let errorDescription: String?
    init(_ message: String) { errorDescription = message }
  }

  /// The checkout the backend runs from: the one chosen in the app, else the one this build came from.
  static func repository() throws -> URL {
    let chosen = UserDefaults.standard.string(forKey: repositoryKey)
    let built = Bundle.main.object(forInfoDictionaryKey: repositoryKey) as? String
    guard let path = chosen ?? built else {
      throw SetupError("This mMac build does not name a Muse Desktop checkout. Choose one.")
    }
    let repository = URL(fileURLWithPath: path).standardizedFileURL
    guard FileManager.default.fileExists(atPath: repository.appending(path: "src/headless/server.ts").path) else {
      throw SetupError("mMac could not find src/headless/server.ts in \(repository.path). Choose the Muse Desktop checkout.")
    }
    return repository
  }

  /// `~/Library/Application Support/mMac`. `MMAC_DATA_FOLDER` overrides it for test runs.
  static func dataFolder() throws -> URL {
    if let folder = ProcessInfo.processInfo.environment["MMAC_DATA_FOLDER"], !folder.isEmpty {
      return URL(fileURLWithPath: folder)
    }
    return try FileManager.default
      .url(for: .applicationSupportDirectory, in: .userDomainMask, appropriateFor: nil, create: true)
      .appending(path: "mMac")
  }

  /// The Node arguments for the backend. Debug builds can run the UI tests' fake backend instead.
  static func backendArguments() -> [String] {
    #if DEBUG
      if let script = ProcessInfo.processInfo.environment["MMAC_BACKEND_SCRIPT"], !script.isEmpty {
        return [script]
      }
    #endif
    return ProcessTransport.serverArguments
  }

  /// The folder for "Open project". The open panel runs in another process that UI tests cannot
  /// drive, so Debug builds take `MMAC_TEST_PROJECT` instead when it is set.
  static func chooseProjectFolder() -> URL? {
    #if DEBUG
      if let folder = ProcessInfo.processInfo.environment["MMAC_TEST_PROJECT"], !folder.isEmpty {
        return URL(fileURLWithPath: folder)
      }
    #endif
    let panel = NSOpenPanel()
    panel.message = "Open a project"
    panel.prompt = "Open project"
    panel.canChooseFiles = false
    panel.canChooseDirectories = true
    panel.canCreateDirectories = true
    return panel.runModal() == .OK ? panel.url : nil
  }
}
```

```swift
import MuseBackend
import Observation
import SwiftUI

/// Asks wait here and show one at a time, as window sheets.
@MainActor @Observable
final class AskQueue {
  struct Pending: Identifiable {
    let ask: Ask
    let continuation: CheckedContinuation<Int, Never>
    var id: Int { ask.ask }
  }

  private(set) var current: Pending?
  private var waiting: [Pending] = []

  /// Shows `ask` when every earlier one is answered, and returns the chosen button's index.
  func present(_ ask: Ask) async -> Int {
    await withCheckedContinuation { continuation in
      let pending = Pending(ask: ask, continuation: continuation)
      if current == nil { current = pending } else { waiting.append(pending) }
    }
  }

  func answer(_ choice: Int) {
    guard let current else { return }
    current.continuation.resume(returning: choice)
    self.current = waiting.isEmpty ? nil : waiting.removeFirst()
  }

  /// Answers every waiting Ask with -1, the cancel choice. Used when the backend stops.
  func cancelAll() {
    current?.continuation.resume(returning: -1)
    for pending in waiting { pending.continuation.resume(returning: -1) }
    current = nil
    waiting = []
  }
}

/// One Ask. The last button is the default and the cancel choice, as Electron's dialogs are.
struct AskSheet: View {
  let ask: Ask
  let answer: (Int) -> Void

  var body: some View {
    VStack(alignment: .leading, spacing: 12) {
      Text(ask.title).font(.headline)
      Text(ask.message)
      if let detail = ask.detail {
        Text(detail)
          .foregroundStyle(.secondary)
          .textSelection(.enabled)
          .fixedSize(horizontal: false, vertical: true)
      }
      HStack {
        Spacer()
        ForEach(Array(ask.buttons.enumerated()), id: \.offset) { index, title in
          Button(title) { answer(index) }
            .keyboardShortcut(index == ask.buttons.count - 1 ? .defaultAction : nil)
        }
      }
    }
    .padding(20)
    .frame(width: 460)
    // Escape chooses the last button, Electron's cancelId.
    .onExitCommand { answer(ask.buttons.count - 1) }
    .interactiveDismissDisabled()
  }
}
```

```swift
struct BlockView: View {
  let block: MarkdownBlock

  var body: some View {
    switch block {
    case .heading(let level, let text):
      Text(text).font(level == 1 ? .title2.bold() : level == 2 ? .title3.bold() : .headline)
    case .paragraph(let text):
      Text(text).textSelection(.enabled).fixedSize(horizontal: false, vertical: true)
    case .code(let language, let code):
      CodeBlockView(language: language, code: code)
    case .quote(let blocks):
      HStack(alignment: .top, spacing: 8) {
        RoundedRectangle(cornerRadius: 1).fill(.tertiary).frame(width: 3)
        MarkdownView(blocks: blocks).foregroundStyle(.secondary)
      }
    case .list(let ordered, let start, let items):
      VStack(alignment: .leading, spacing: 4) {
        ForEach(Array(items.enumerated()), id: \.offset) { index, item in
          HStack(alignment: .firstTextBaseline, spacing: 6) {
            Text(marker(ordered: ordered, number: start + index, checked: item.checked))
              .monospacedDigit()
              .foregroundStyle(.secondary)
            MarkdownView(blocks: item.blocks)
          }
        }
      }
    case .table(let header, let rows):
      TableBlockView(header: header, rows: rows)
    case .rule:
      Divider()
    }
  }

  }
```

```swift
  @State private var following = true

  var body: some View {
    let entries = TranscriptEntry.build(view.items)
    ScrollViewReader { proxy in
      ScrollView {
        LazyVStack(alignment: .leading, spacing: 18) {
          if entries.isEmpty, view.approvals.isEmpty, view.questions.isEmpty, view.error == nil {
            ContentUnavailableView(
              "Start a conversation", systemImage: "bubble.left.and.bubble.right",

        }
        .padding(20)

        .frame(maxWidth: .infinity)
      }
      .onScrollGeometryChange(for: Bool.self) { geometry in
```
