# mMac M6 (Muse Code controls) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** mMac gets the Muse Code controls it lacks, in this order: the SDK raise, goals (feature 14), conversation fork (15), background control (16) and skills (17).

**Architecture:** Each feature follows M5a's pattern: one call in `src/main/muse-host.ts`, one method in `src/headless/backend.ts`, one typed call in MuseBackend, one rule in MuseKit, and one view. The skill catalog is the exception: a new file, `src/headless/skills.ts`, reads and writes it through the CLI, because `skill/setActivation` needs a session and `skill/list` does not show the change.

**Status:** Tasks 0 to 12 finished on 2026-11-01. Task 13 started and is paused on Dom's word. Its first UI test run stopped when the Automation Mode stop gesture ended the session, so it says nothing about the code (see "Run 1 of the UI tests"). No UI test has finished, and `testM6AgainstTheFakeBackend` has never run. "Background results" records what passed with no screen. Task 13 resumes only on Dom's word, and Task 14 merges.

**Order (Dom, 2026-11-01):** no live run and no UI test run happens until M6 is finished. M6 therefore no longer waits for PR 1: PR 1 waits for M6. Background checks run whenever a task needs them.

**Tech Stack:** TypeScript, zod, Vitest; Swift 6, SwiftUI (macOS 15), Swift Testing, XCTest UI tests, XcodeGen. No new dependency. `@muse-code/sdk` goes from 1.4.7 to 1.4.14.

**Choices this plan makes** (Task 12 records each in `docs/decisions.md`):

| Choice                                                                                  | Why                                                                                                                   |
| --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| One backend method for the five goal verbs, and one for the seven task controls.        | The verbs share one shape and one check. Twelve methods would repeat the same six lines.                              |
| The host finds a reopened conversation's goal by paging backward, at most four pages.   | `session/read` carries no goal. A conversation with more than 2,000 later events shows no goal until the next change. |
| Fork points are the last completed Muse message of each completed turn.                 | `lastTurnId` must name a completed turn. One button per turn keeps the transcript quiet.                              |
| The Agents tab reads `task/list` when the set of running items changes. It never polls. | Muse has no event for the list, and each ending task changes an item.                                                 |
| Stop all asks first. A single Stop does not.                                            | A single Stop matches the composer's Stop. Stop all can end work Dom cannot see on screen.                            |
| The Skills pane uses the CLI. The `/` popup uses `skill/list`, then the CLI catalog.    | Settings has no session. `skill/list` gives exact selectors, but only on a loaded conversation.                       |
| The catalog passes `--workspace` only for a project that is already trusted.            | Opening Settings must never raise a trust Ask.                                                                        |
| A skill row needs a conversation. With none, the `/` popup lists no skills.             | `turn/start` needs a session. Creating one for a skill adds a second path through `send`.                             |

```ts
  /**
   * One of Muse's five goal verbs (msp.d.ts, `goal/set`). On an idle conversation, set, edit and
   * resume can start a turn. The new value arrives through `session/goalChanged`.
   */
  async goal(sessionId: string, verb: GoalVerb, objective?: string) {
    await this.resume(sessionId)
    await this.connection.command(
      `goal/${verb}`,
      { sessionId, ...(objective === undefined ? {} : { objective }) },
      { maxAttempts: 1 },
    )
  }

  /**
   * `session/read` carries no goal, so read the view backward to the latest goal event. A failure
   * leaves the goal unset: the strip is a convenience, and the next change brings it back.
   */
  private async restoreGoal(live: LiveSession) {
    const sessionId = live.view.session.sessionId
    const schema = z.object({
      events: z.array(z.object({ method: z.string(), params: z.record(z.string(), z.unknown()) })),
      nextCursor: z.string().nullable(),
    })
    try {
      let cursor: string | undefined
      for (let page = 0; page < 4; page++) {
        const { events, nextCursor } = schema.parse(
          await this.connection.request('view/page', {
            sessionId,
            direction: 'backward',
            limit: 500,
            ...(cursor ? { cursor } : {}),
          }),
        )
        const found = [...events].reverse().find((event) => event.method === 'session/goalChanged')
        if (found) {
          live.view.goal = sessionGoalSchema.nullable().parse(found.params.goal) ?? undefined
          return
        }
        if (!nextCursor) return
        cursor = nextCursor
      }
    } catch (error) {
      console.error(`Could not read the goal: ${messageOf(error)}`)
    }
  }
```

```swift
import MuseBackend

/// The goal strip's rules and the `/goal` grammar. Muse's status is a free string, so an unknown
/// status shows as it is and offers only Edit and Clear.
public enum GoalRules {
  public enum Command: Equatable, Sendable {
    case set(String)
    case edit(String)
    case verb(String)
    case help
  }

  public static let help = "Use /goal <objective>, /goal pause, /goal resume, or /goal clear."
  /// Shown beside the Edit field and in the Help sheet: a goal costs allowance.
  public static let startsWork = "Setting a goal starts Muse working on it."

  /// A lone `pause`, `resume` or `clear` is a verb. Any other text is the objective.
  public static func command(_ argument: String, goal: SessionGoal?) -> Command {
    let lowered = argument.lowercased()
    if argument.isEmpty { return .help }
    if ["pause", "resume", "clear"].contains(lowered) { return .verb(lowered) }
    return goal == nil ? .set(argument) : .edit(argument)
  }

  public static func canPause(_ goal: SessionGoal) -> Bool { goal.status == "active" }
  public static func canResume(_ goal: SessionGoal) -> Bool { goal.status == "paused" }

  /// "Active · 40%". The percent shows only above zero, and may pass 100.
  public static func detail(_ goal: SessionGoal) -> String {
    let status = goal.status.prefix(1).uppercased() + goal.status.dropFirst()
    guard goal.percentComplete > 0 else { return status }
    return "\(status) · \(Int(goal.percentComplete))%"
  }
}
```

```swift
import MuseBackend

/// Where the transcript offers a fork: the last completed Muse message of each completed turn.
public enum ForkRules {
  /// Item id to turn id. The active turn has no fork point: `session/fork` refuses it.
  public static func points(_ items: [TranscriptItem], activeTurnId: String?) -> [String: String] {
    var unfinished = Set<String>()
    var last: [String: String] = [:]
    for item in items where item.retracted != true {
      guard let turn = item.turnId else { continue }
      if item.status == "inProgress" { unfinished.insert(turn) }
      if item.kind == "agentMessage", item.status == "completed" { last[turn] = item.itemId }
    }
    if let activeTurnId { unfinished.insert(activeTurnId) }
    return Dictionary(
      uniqueKeysWithValues: last.filter { !unfinished.contains($0.key) }.map { ($0.value, $0.key) })
  }
}
```

```swift
import MuseBackend

/// One open workflow run in the Agents tab.
public struct WorkflowRow: Equatable, Sendable, Identifiable {
  public let id: String
  public let runId: String
  public let title: String
  public let paused: Bool

  public static func build(_ items: [TranscriptItem]) -> [WorkflowRow] {
    items.compactMap { item in
      guard item.kind == "workflow", item.retracted != true, item.stopAvailable == true,
        let runId = item.workflowRunId
      else { return nil }
      return WorkflowRow(
        id: item.itemId, runId: runId,
        title: ToolPresentation.first(item.objective, item.label) ?? "Workflow",
        paused: item.paused == true)
    }
  }
}

/// A tool running in the turn's foreground, which Muse may send to the background.
public struct RunningToolRow: Equatable, Sendable, Identifiable {
  public let id: String
  public let title: String

  public static func build(_ items: [TranscriptItem], listed: [BackgroundTask]) -> [RunningToolRow] {
    let background = Set(listed.map(\.taskId))
    return items.compactMap { item in
      guard item.kind == "toolCall", item.status == "inProgress", item.retracted != true,
        !background.contains(item.itemId)
      else { return nil }
      return RunningToolRow(id: item.itemId, title: ToolPresentation.first(item.tool) ?? "Tool")
    }
  }
}

public enum BackgroundRules {
  public static let stopAllTitle = "Stop all background tasks?"
  public static let stopAllDetail = "Muse stops every background task in this conversation."

  /// Muse has no event for `task/list`, but each task that starts or ends changes an item. The
  /// tab reads the list again when this value changes.
  public static func signature(_ items: [TranscriptItem]) -> String {
    items.filter {
      $0.status == "inProgress" && ["toolCall", "subagent", "workflow"].contains($0.kind)
    }
    .map(\.itemId).sorted().joined(separator: ",")
  }

  /// A task row's name: its tool when it has one, else its kind.
  public static func title(_ task: BackgroundTask) -> String { task.tool ?? task.kind }
}
```

```ts
  return project ? ['--workspace', project, '--trust-workspace'] : []

/** Runs the CLI and returns its standard output. Tests pass a fake. */

export const runCli: RunCli = async (cliPath, args) => {
  const cli = await discoverCli(cliPath)
  const { stdout } = await execCli(cli.path, args, {
    env: cli.environment,
    timeout: 15000,
    maxBuffer: 16 * 1024 * 1024,
    encoding: 'utf8',
  })
  return String(stdout)
}

export function createSkills(run: RunCli = runCli) {
  return {
    /** Every skill Muse knows, with its activation. A project adds that project's skills. */
    async readCatalog(cliPath: string, project?: string): Promise<SkillEntry[]> {
      const output = await run(cliPath, [
        'skills',
        'list',
        '--source',
        'all',
        '--json',
        ...workspace(project),
      ])

      } catch {
        throw new Error('Muse Code did not return a skill list.')
      }
      return parsed.skills.map((skill) => ({
        id: skill.id,
        name: skill.name,
        displayName: skill.display_name || skill.name,
        description: skill.description ?? '',
        scope: skill.scope,
        activation: skill.activation,
      }))
    },

      cliPath: string,
```

```swift
import MuseBackend

/// A skill the draft asks to run.
public struct SkillInvocation: Equatable, Sendable {
  public let selector: String
  public let arguments: String
  public init(selector: String, arguments: String) {
    self.selector = selector
    self.arguments = arguments
  }
}

/// One row of the `/` popup.
public struct SlashRow: Equatable, Sendable, Identifiable {
  public let name: String
  public let description: String
  public var id: String { name }
}

/// The `/` popup's rows and keys: the commands, as `ComposerCommand` rules them, then the skills.
/// A skill named like a command is left out, so the command wins.
public enum SlashMenu {
  private static let commandNames = Set(ComposerCommand.allCases.map(\.name))

  private static func available(_ skills: [SkillRow]) -> [SkillRow] {
    skills.filter { !commandNames.contains($0.selector.lowercased()) }
  }

  /// Skill selectors also hold digits, `_` and `:`, which a command name does not.
  private static func isSelectorScalar(_ scalar: Unicode.Scalar) -> Bool {
    switch scalar {
    case "a"..."z", "A"..."Z", "0"..."9", "-", "_", ":": true
    default: false
    }
  }

  public static func rows(for draft: String, skills: [SkillRow]) -> [SlashRow] {
    let commands = ComposerCommand.menu(for: draft).map {
      SlashRow(name: $0.name, description: $0.description)
    }
    let scalars = draft.unicodeScalars
    guard scalars.first == "/", scalars.dropFirst().allSatisfy(isSelectorScalar) else {
      return commands
    }
    let typed = String(scalars.dropFirst()).lowercased()
    return commands
      + available(skills).filter { $0.selector.lowercased().hasPrefix(typed) }.map {
        SlashRow(name: $0.selector, description: $0.description)
      }
  }

  /// The skill the whole draft names, or nil. The first word must be a known selector.
  public static func invocation(_ draft: String, skills: [SkillRow]) -> SkillInvocation? {
    let text = JSWhitespace.trim(draft).unicodeScalars
    guard text.first == "/" else { return nil }
    let start = text.index(after: text.startIndex)
    var end = start
    while end < text.endIndex, isSelectorScalar(text[end]) { end = text.index(after: end) }
    guard end > start, end == text.endIndex || JSWhitespace.contains(text[end]) else { return nil }
    let name = String(text[start..<end])
    guard available(skills).contains(where: { $0.selector == name }) else { return nil }
    return SkillInvocation(selector: name, arguments: JSWhitespace.trim(String(text[end...])))
  }

  /// `ComposerCommand.slashKeyAction`'s keys, over both kinds of row.
  public static func keyAction(
    _ key: SlashKey, draft: String, index: Int, skills: [SkillRow]
  ) -> SlashKeyAction {
    let menu = rows(for: draft, skills: skills)
    guard !menu.isEmpty else { return .pass }
    let index = min(max(index, 0), menu.count - 1)
    switch key {
    case .down:
      return .select((index + 1) % menu.count)
    case .up:
      return .select((index - 1 + menu.count) % menu.count)
    case .tab:
      return .setDraft("/\(menu[index].name) ")
    case .enter:
      if menu.contains(where: { "/\($0.name)".lowercased() == draft.lowercased() }) {
        return .submit
      }
      return .setDraft("/\(menu[index].name) ")
    case .escape:
      return .setDraft(draft + " ")
    }
  }
}
```
