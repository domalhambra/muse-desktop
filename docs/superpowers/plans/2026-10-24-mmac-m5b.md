# mMac M5b (usage and services) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Muse Code may run this plan instead; it follows the same tasks in order with its own skills. Every step names its files, its code and its check.

**Goal:** mMac gets the five features the parity spec puts in M5b, in this order: the conversation's usage and cost (feature 11), the session limit (12) and the weekly limit (13), local scheduled tasks (9), and the pull request monitor shown as change cards (10).

**Architecture:** Usage follows M5a's pattern. The host (`src/main/muse-host.ts`) reads `usage/read` at connect and folds `usage/changed`, `cumulative.cost` and `error.quota`. The backend exposes one method and one event, and MuseKit holds the rules. Scheduled tasks and the PR monitor are new modules under `src/headless/` (`schedule.ts`, `schedule-rules.ts` and `pull-request.ts`), each with its own Vitest suite, typed Swift calls, MuseKit rules and views. Neither module touches `src/main/`. The protocol number rises to 3.

**Status:** planned on 2026-10-24, on the branch `mac-m5b`, after M5a merged into `extensions` as PR 13 (`8a75c92`). Nothing is built yet.

**Tech Stack:** TypeScript, zod, Vitest, `tsx`, `cron-parser` 5 (the one new dependency); the GitHub CLI `gh`; Swift 6, SwiftUI (macOS 15), Swift Testing, XCTest UI tests, XcodeGen.

**Inputs:**

- The spec, `docs/superpowers/specs/2026-10-23-mmac-parity-design.md`, section "M5b: usage and the two backend modules", at `471318b`. It is the source for every decision below.
- The SDK's own types, `node_modules/@muse-code/sdk/dist/src/msp.d.ts` (1.4.7). Line numbers below are from that file.
- The M5a plan, `docs/superpowers/plans/2026-10-23-mmac-m5a.md`, for the patterns this plan repeats. These are the host folds, the backend method, the Swift call and model, and the MuseKit rule with its view.
- `docs/decisions.md`. Task 15 adds "2026-10-24: mMac M5b" there.

**Dom's decisions for M5b (2026-10-23):**

- Usage and limits join M5b as features 11 to 13 and are built first. Next come scheduled tasks, then the PR monitor.
- The limits show as one line at the bottom of the sidebar, with a popover. The conversation's tokens and cost join the inspector's context card.
- The footer line turns amber at 80% and red at 100%. A turn that a limit stops shows a plain banner. No system notifications.
- The PR monitor's main view is the change card: a headline, a before-and-after section, the delivery track, a risk light, dependencies, Accept and Ask why.

**Choices this plan makes** (Task 15 records each in `docs/decisions.md`):

| Choice                                                                                                                                                                      | Why                                                                                                                                                                                                                                                                      |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The stop banner names the limit by matching `quota.resetsAtMs` to the window's or the weekly block's reset time, within 60 seconds.                                         | `QuotaDetail.limitKind` has one value today, `tierLimit` (`msp.d.ts:1056`), so the kind cannot tell the two limits apart. A reset time that matches neither gives "Usage limit reached".                                                                                 |
| A custom cron expression's minute field must be one number from 0 to 59.                                                                                                    | This puts runs at least an hour apart, as the spec's floor requires, with a rule both sides can check without a cron engine in Swift. Desktop allows more expressions. This one blocks only expressions that would fire more than once an hour.                          |
| The backend computes `nextRunAt`. Swift only formats it.                                                                                                                    | Cron evaluation stays in one place, `cron-parser`.                                                                                                                                                                                                                       |
| Catch-up and due detection are one rule: the latest fire time after the last check, and no older than seven days.                                                           | A wake, a restart and a normal tick then share one tested path. The spec's "one catch-up per task for the latest missed time within seven days" falls out of it.                                                                                                         |
| A scheduled run needs its folder to be trusted already, and records a skip when it is not.                                                                                  | A run that nobody watches must not stop on a trust Ask.                                                                                                                                                                                                                  |
| `gh` runs with the backend's `PATH`, plus `/opt/homebrew/bin` and `/usr/local/bin`.                                                                                         | mMac starts from Finder with a short `PATH`. These are the two places Homebrew installs `gh`.                                                                                                                                                                            |
| Live means merged into the repository's default branch, or a successful GitHub deployment of the merge commit. Only the five newest merged PRs are checked for deployments. | This is the spec's rule. The cap keeps a list read to at most twelve `gh` calls. The fork's PRs go into `extensions` while `main` mirrors upstream, so they stop at Accepted unless a deployment exists. The card says "Accepted into extensions" and leaves Live unlit. |
| After a merge, the Accepted card of a worktree conversation offers "Archive conversation", in place of an Archive button on the "PR merged" toast.                          | The toast stays the plain notice M4a built; the card already holds the PR's actions.                                                                                                                                                                                     |
| Accept and Merge when ready ask in the backend before they merge.                                                                                                           | The backend's Ask is the pattern for every action that changes something outside mMac (trust, revert, worktree remove).                                                                                                                                                  |
| A new event, `schedules-changed`, joins the spec's `schedule-run-started`.                                                                                                  | A skip or a failure changes the history too, and Settings must redraw it.                                                                                                                                                                                                |

```ts
/** `SubscriptionUsage` (msp.d.ts:2543), the payload of `usage/read` and `usage/changed`. */
const subscriptionUsageSchema = z.object({
  observedAtMs: z.number(),
  tier: z.string(),
  window: z.object({
    usedPercent: z.number(),
    resetsAtMs: z.number(),
    windowDurationMins: z.number(),
  }),
  weekly: z.object({ usedPercent: z.number(), resetsAtMs: z.number() }),

function toLimits(value: unknown): SubscriptionLimits {
  const usage = subscriptionUsageSchema.parse(value)
  return {
    observedAt: usage.observedAtMs,
    tier: usage.tier,

      resetsAt: usage.window.resetsAtMs,
      minutes: usage.window.windowDurationMins,

  }
}
```

```ts
  /** `usage/read` (msp.d.ts:3030): omitted when Muse has observed nothing. A CLI without the method keeps null. */
  private async readLimits() {
    try {
      const result = z
        .object({ usage: z.unknown().optional() })
        .parse(await this.connection.request('usage/read', {}))
      if (result.usage === undefined) return
      this.limits = toLimits(result.usage)
      this.emit({ type: 'usage-changed', limits: this.limits })
    } catch {
      // An older CLI, or a read that failed: the footer stays hidden.
    }
  }
```

```swift
import Foundation
import MuseBackend

/// The words of the usage footer, its popover, the context card's tokens line and the stop banner.
public enum UsageRules {
  public enum Level: Int, Comparable, Equatable, Sendable {
    case normal, warning, full
    public static func < (lhs: Level, rhs: Level) -> Bool { lhs.rawValue < rhs.rawValue }
  }

  /// Amber from 80, red from 100.
  public static func level(_ percent: Int) -> Level {
    percent >= 100 ? .full : percent >= 80 ? .warning : .normal
  }

  /// "5-hour" for 300 minutes, "90-minute" when the length is not whole hours.
  public static func windowLabel(minutes: Int) -> String {
    minutes % 60 == 0 ? "\(minutes / 60)-hour" : "\(minutes)-minute"
  }

  /// True when the limit has reset since Muse observed it: its number no longer holds.
  public static func isStale(resetsAt: Double, observedAt: Double, now: Date) -> Bool {
    observedAt < resetsAt && now.timeIntervalSince1970 * 1000 >= resetsAt
  }

  public static func footer(_ limits: SubscriptionLimits, now: Date) -> String {
    let window = windowLabel(minutes: limits.window.minutes)
    let first =
      isStale(resetsAt: limits.window.resetsAt, observedAt: limits.observedAt, now: now)
      ? "\(window) reset" : "\(window) \(limits.window.usedPercent)%"
    let second =
      isStale(resetsAt: limits.weekly.resetsAt, observedAt: limits.observedAt, now: now)
      ? "Week reset" : "Week \(limits.weekly.usedPercent)%"
    return "\(first) \u{00B7} \(second)"
  }

  /// The higher level of the limits whose numbers still hold.
  public static func footerLevel(_ limits: SubscriptionLimits, now: Date) -> Level {
    var levels: [Level] = [.normal]
    if !isStale(resetsAt: limits.window.resetsAt, observedAt: limits.observedAt, now: now) {
      levels.append(level(limits.window.usedPercent))
    }
    if !isStale(resetsAt: limits.weekly.resetsAt, observedAt: limits.observedAt, now: now) {
      levels.append(level(limits.weekly.usedPercent))
    }
    return levels.max() ?? .normal
  }

  /// "resets 3:40 PM" today, "resets Mon 9:00 AM" on another day.
  public static func resetText(
    _ resetsAt: Double, now: Date, calendar: Calendar = .current, locale: Locale = .current
  ) -> String {
    "resets \(when(resetsAt, now: now, calendar: calendar, locale: locale))"
  }

  public static func costText(_ cost: SessionCost) -> String {
    let amount = "~$" + String(format: "%.2f", locale: Locale(identifier: "en_US_POSIX"), cost.usd)
    return cost.partial ? "\(amount) (partial)" : amount
  }

  /// The context card's line: "128,400 tokens · ~$0.84". Nil before the first reply reports usage.
  public static func tokensLine(usage: Usage?, cost: SessionCost?) -> String? {
    guard let usage else { return nil }
    let tokens = "\(usage.total.formatted(.number.locale(Locale(identifier: "en_US")))) tokens"
    return cost.map { "\(tokens) \u{00B7} \(costText($0))" } ?? tokens
  }

  /// The banner that replaces a quota stop's raw error. `limitKind` cannot tell the two limits apart
  /// (msp.d.ts:1056), so the reset time does, within a minute.
  public static func stopBanner(
    _ quota: QuotaStop, limits: SubscriptionLimits?, now: Date, calendar: Calendar = .current,
    locale: Locale = .current
  ) -> String {
    let name: String
    if let limits, abs(limits.window.resetsAt - quota.resetsAt) <= 60_000 {
      name = "Session limit"
    } else if let limits, abs(limits.weekly.resetsAt - quota.resetsAt) <= 60_000 {
      name = "Weekly limit"
    } else {
      name = "Usage limit"
    }
    let at = when(quota.resetsAt, now: now, calendar: calendar, locale: locale)
    let sameDay = calendar.isDate(Date(timeIntervalSince1970: quota.resetsAt / 1000), inSameDayAs: now)
    return "\(name) reached. Resets \(sameDay ? "at " : "")\(at)."
  }

  /// VoiceOver's label for one limit; color never carries the meaning alone.
  public static func spoken(name: String, percent: Int, reset: String) -> String {
    "\(name) \(percent) percent used, \(reset)"
  }

  private static func when(_ epochMs: Double, now: Date, calendar: Calendar, locale: Locale) -> String {
    let date = Date(timeIntervalSince1970: epochMs / 1000)
    var time = Date.FormatStyle(date: .omitted, time: .shortened, locale: locale, calendar: calendar)
    time.timeZone = calendar.timeZone
    if calendar.isDate(date, inSameDayAs: now) { return date.formatted(time) }
    var day = Date.FormatStyle(locale: locale, calendar: calendar).weekday(.abbreviated)
    day.timeZone = calendar.timeZone
    return "\(date.formatted(day)) \(date.formatted(time))"
  }
}
```

```ts
import { CronExpressionParser } from 'cron-parser'
import { z } from 'zod'
import { approvalModeSchema } from '../shared/protocol'

// Scheduled tasks' pure rules: what a task is, when it fires, and when it last came due.
// src/headless/schedule.ts runs them; mMac's ScheduleRules formats what this returns.

export const presetSchema = z.enum(['hourly', 'daily', 'weekdays', 'weekly', 'manual', 'custom'])

export const scheduleSchema = z.object({
  id: z.string().min(1).max(100),
  name: z.string().trim().min(1).max(100),
  prompt: z.string().trim().min(1).max(20000),
  folder: z.string().min(1).max(4096),
  preset: presetSchema,
  minute: z.number().int().min(0).max(59),
  hour: z.number().int().min(0).max(23),
  weekday: z.number().int().min(0).max(6),
  cron: z.string().max(100).optional(),
  approvalMode: approvalModeSchema,
  modelId: z.string().nullable(),
  worktree: z.boolean(),
  enabled: z.boolean(),
  createdAt: z.number(),
})
export type Schedule = z.infer<typeof scheduleSchema>

const SEVEN_DAYS = 7 * 24 * 60 * 60 * 1000

export function cronFor(schedule: Schedule): string | null {
  const { minute: m, hour: h, weekday: d } = schedule
  switch (schedule.preset) {
    case 'hourly':
      return `${m} * * * *`
    case 'daily':
      return `${m} ${h} * * *`
    case 'weekdays':
      return `${m} ${h} * * 1-5`
    case 'weekly':
      return `${m} ${h} * * ${d}`
    case 'custom':
      return schedule.cron ?? null
    case 'manual':
      return null
  }
}

/** Undefined when the custom expression is usable; otherwise the message for the form. */
export function checkCron(expression: string): string | undefined {
  const fields = expression.trim().split(/\s+/)
  if (fields.length !== 5)
    return 'A custom schedule has five fields: minute, hour, day, month, weekday.'
  if (!/^\d{1,2}$/.test(fields[0]) || Number(fields[0]) > 59)
    return 'A custom schedule runs at most once an hour, so its minute must be one number from 0 to 59.'
  try {
    CronExpressionParser.parse(expression)
    return undefined
  } catch (error) {
    return `Muse could not read this schedule: ${error instanceof Error ? error.message : String(error)}`
  }
}

/**
 * The latest fire time after `since` and at or before `now`, no older than seven days: one run,
 * whether this is a minute tick, a restart or a wake. Null when nothing came due.
 */
export function dueTime(
  schedule: Schedule,
  since: number,
  now: number,
  tz?: string,
): number | null {
  const expression = schedule.enabled ? cronFor(schedule) : null
  if (!expression) return null
  // prev() is strictly before currentDate, so start one second past now to include it.
  const latest = CronExpressionParser.parse(expression, { currentDate: new Date(now + 1000), tz })
    .prev()
    .toDate()
    .getTime()
  return latest > since && latest >= now - SEVEN_DAYS ? latest : null
}

export function nextRun(schedule: Schedule, after: number, tz?: string): number | null {
  const expression = cronFor(schedule)
  if (!expression) return null
  return CronExpressionParser.parse(expression, { currentDate: new Date(after), tz })
    .next()
    .toDate()
    .getTime()
}
```

```ts
import { randomUUID } from 'node:crypto'
import { readFile, rename, writeFile } from 'node:fs/promises'
import { z } from 'zod'
import type { AppEvent } from '../shared/protocol'
import { checkCron, dueTime, nextRun, scheduleSchema, type Schedule } from './schedule-rules'

// Scheduled tasks, as Desktop's Scheduled page: checked every minute while mMac runs, one run at a
// time, with a capped history. Pure timing lives in schedule-rules.ts.

const runSchema = z.object({
  at: z.number(),
  scheduledFor: z.number().nullable(),
  outcome: z.enum(['started', 'skipped', 'failed']),
  reason: z.string().optional(),
  sessionId: z.string().optional(),
})
export type ScheduleRun = z.infer<typeof runSchema>
const storeSchema = z.object({
  schedules: z.array(scheduleSchema),
  history: z.record(z.string(), z.array(runSchema)),
  lastCheckedAt: z.number(),
})
type Store = z.infer<typeof storeSchema>
export const scheduleInputSchema = scheduleSchema
  .omit({ id: true, createdAt: true })
  .extend({ id: z.string().min(1).max(100).optional() })
export type ScheduleInput = z.infer<typeof scheduleInputSchema>
export type ScheduleEntry = { schedule: Schedule; nextRunAt: number | null; history: ScheduleRun[] }

const HISTORY = 50
const BUSY = 'Another scheduled task was running.'

export type SchedulerDeps = {
  file: string
  now?: () => number
  /** IANA time zone for the cron rules; the Mac's own when omitted. Tests pass 'UTC'. */
  tz?: string
  /** Creates the conversation, sets its mode and sends the prompt. Returns the session id. */
  start: (schedule: Schedule) => Promise<string>
  /** True while the session's turn runs. */
  isRunning: (sessionId: string) => boolean
  emit: (event: AppEvent) => void
}

export class Scheduler {
  private store: Store = { schedules: [], history: {}, lastCheckedAt: 0 }
  private active: { starting: boolean; sessionId?: string } | null = null
  private timer?: ReturnType<typeof setInterval>
  private writes: Promise<void> = Promise.resolve()

  constructor(private deps: SchedulerDeps) {}

  private now() {
    return (this.deps.now ?? Date.now)()
  }

  async load() {
    try {
      this.store = storeSchema.parse(JSON.parse(await readFile(this.deps.file, 'utf8')))
    } catch {
      this.store = { schedules: [], history: {}, lastCheckedAt: 0 }
    }
  }

  /** Checks now, then every minute. */
  start() {
    this.stop()
    this.timer = setInterval(() => void this.tick(), 60_000)
    void this.tick()
  }

  stop() {
    if (this.timer) clearInterval(this.timer)
    this.timer = undefined
  }

  list(): ScheduleEntry[] {
    const now = this.now()
    return this.store.schedules.map((schedule) => ({
      schedule,
      nextRunAt: schedule.enabled ? nextRun(schedule, now, this.deps.tz) : null,
      history: [...(this.store.history[schedule.id] ?? [])].reverse(),
    }))
  }

  async save(value: unknown): Promise<ScheduleEntry> {
    const input = scheduleInputSchema.parse(value)
    if (input.preset === 'custom') {
      const problem = checkCron(input.cron ?? '')
      if (problem) throw new Error(problem)
    }
    const existing = this.store.schedules.find((schedule) => schedule.id === input.id)
    const schedule: Schedule = {
      ...input,
      id: existing?.id ?? randomUUID(),
      createdAt: existing?.createdAt ?? this.now(),
    }
    this.store.schedules = existing
      ? this.store.schedules.map((entry) => (entry.id === schedule.id ? schedule : entry))
      : [...this.store.schedules, schedule]
    await this.write()
    return this.list().find((entry) => entry.schedule.id === schedule.id)!
  }

  async remove(id: string) {
    this.store.schedules = this.store.schedules.filter((schedule) => schedule.id !== id)
    delete this.store.history[id]
    await this.write()
    this.deps.emit({ type: 'schedules-changed' })
  }

  async setEnabled(id: string, enabled: boolean) {
    this.store.schedules = this.store.schedules.map((schedule) =>
      schedule.id === id ? { ...schedule, enabled } : schedule,
    )
    await this.write()
  }

  async runNow(id: string) {
    const schedule = this.store.schedules.find((entry) => entry.id === id)
    if (!schedule) throw new Error('This scheduled task no longer exists.')
    if (this.busy())
      throw new Error('Another scheduled task is running. Try again when it finishes.')
    await this.run(schedule, null)
  }

  async tick() {
    const now = this.now()
    for (const schedule of this.store.schedules) {
      const since = Math.max(this.store.lastCheckedAt, schedule.createdAt)
      const due = dueTime(schedule, since, now, this.deps.tz)
      if (due === null) continue
      if (this.busy())
        this.record(schedule.id, { at: now, scheduledFor: due, outcome: 'skipped', reason: BUSY })
      else await this.run(schedule, due)
    }
    this.store.lastCheckedAt = now
    await this.write()
  }

  private busy() {
    if (!this.active) return false
    if (this.active.starting) return true
    if (this.active.sessionId && this.deps.isRunning(this.active.sessionId)) return true
    this.active = null
    return false
  }

  private async run(schedule: Schedule, scheduledFor: number | null) {
    this.active = { starting: true }
    try {
      const sessionId = await this.deps.start(schedule)
      this.active = { starting: false, sessionId }
      this.record(schedule.id, { at: this.now(), scheduledFor, outcome: 'started', sessionId })
      this.deps.emit({
        type: 'schedule-run-started',
        scheduleId: schedule.id,
        name: schedule.name,
        sessionId,
      })
    } catch (error) {
      this.active = null
      this.record(schedule.id, {
        at: this.now(),
        scheduledFor,
        outcome: 'failed',
        reason: error instanceof Error ? error.message : String(error),
      })
    }
    await this.write()
  }

  private record(id: string, run: ScheduleRun) {
    this.store.history[id] = [...(this.store.history[id] ?? []), run].slice(-HISTORY)
    this.deps.emit({ type: 'schedules-changed' })
  }

  /** A temporary file with mode 600, renamed over the store: no half-written file after a crash. */
  private write() {
    const data = JSON.stringify(this.store, null, 2)
    this.writes = this.writes.then(async () => {
      const temporary = `${this.deps.file}.${process.pid}.tmp`
      await writeFile(temporary, data, { mode: 0o600 })
      await rename(temporary, this.deps.file)
    })
    return this.writes
  }
}
```

```swift
  public static let presets = ["hourly", "daily", "weekdays", "weekly", "manual", "custom"]

  public static func validate(_ input: ScheduleInput) -> String? {
    if input.name.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty { return "Give the task a name." }
    if input.prompt.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty { return "Write the instructions Muse runs." }

    guard input.preset == "custom" else { return nil }
    let fields = (input.cron ?? "").split(whereSeparator: \.isWhitespace)
    if fields.count != 5 { return "A custom schedule has five fields: minute, hour, day, month, weekday." }
    if let minute = Int(fields[0]), (0...59).contains(minute), fields[0].allSatisfy(\.isNumber) { return nil }
    return "A custom schedule runs at most once an hour, so its minute must be one number from 0 to 59."
  }

  public static func trigger(_ schedule: Schedule, calendar: Calendar = .current, locale: Locale = .current) -> String {
    let time = clock(hour: schedule.hour, minute: schedule.minute, calendar: calendar, locale: locale)
    switch schedule.preset {
    case "hourly": return "Every hour at :\(String(format: "%02d", schedule.minute))"
    case "daily": return "Every day at \(time)"
    case "weekdays": return "Weekdays at \(time)"
    case "weekly":
      var symbols = calendar
      symbols.locale = locale
      return "\(symbols.weekdaySymbols[schedule.weekday % 7])s at \(time)"
    case "custom": return "Custom: \(schedule.cron ?? "")"
    default: return "Manual"
    }
  }

  public static func nextRun(
    _ entry: ScheduleEntry, now: Date, calendar: Calendar = .current, locale: Locale = .current
  ) -> String {
    if !entry.schedule.enabled { return "Paused" }
    guard let next = entry.nextRunAt else { return "Runs only with Run now" }
    return "Next run \(when(next, now: now, calendar: calendar, locale: locale))"
  }

  public static func historyLine(
    _ run: ScheduleRun, now: Date, calendar: Calendar = .current, locale: Locale = .current
  ) -> String {
    let at = when(run.at, now: now, calendar: calendar, locale: locale)
    let verb = run.outcome == "started" ? "Started" : run.outcome == "skipped" ? "Skipped" : "Failed"
    return run.reason.map { "\(verb) \(at): \($0)" } ?? "\(verb) \(at)"
  }

  public static func finishedNotice(name: String) -> String { "Scheduled task \(name) finished" }

  private static func clock(hour: Int, minute: Int, calendar: Calendar, locale: Locale) -> String {
    var style = Date.FormatStyle(date: .omitted, time: .shortened, locale: locale, calendar: calendar)
    style.timeZone = calendar.timeZone
    let date = calendar.date(from: DateComponents(year: 2026, month: 1, day: 5, hour: hour, minute: minute)) ?? .now
    return date.formatted(style)
  }

  /// "today 3:40 PM", or "Mon 9:00 AM" on another day.
  private static func when(_ epochMs: Double, now: Date, calendar: Calendar, locale: Locale) -> String {
    let date = Date(timeIntervalSince1970: epochMs / 1000)
    var time = Date.FormatStyle(date: .omitted, time: .shortened, locale: locale, calendar: calendar)
    time.timeZone = calendar.timeZone
    if calendar.isDate(date, inSameDayAs: now) { return "today \(date.formatted(time))" }
    var day = Date.FormatStyle(locale: locale, calendar: calendar).weekday(.abbreviated)
    day.timeZone = calendar.timeZone
    return "\(date.formatted(day)) \(date.formatted(time))"
  }
}
```

```ts
import { execFile } from 'node:child_process'
import { promisify } from 'node:util'
import { z } from 'zod'
import type { PullRequest, PullRequestCheck } from '../shared/protocol'

// The PR monitor and the change cards, through the GitHub CLI. mMac never calls GitHub itself:
// gh holds the person's sign-in.

const execute = promisify(execFile)
const FIELDS =
  'number,title,url,state,isDraft,reviewDecision,mergeStateStatus,baseRefName,headRefName,mergedAt,mergeCommit,body,files,statusCheckRollup'
export const GH_MISSING =
  'GitHub CLI (gh) is not installed. Install it, then run gh auth login in Terminal.'
export const GH_SIGNED_OUT = 'GitHub CLI is not signed in. Run gh auth login in Terminal.'
const DEPLOYMENT_CHECKS = 5

type Options = { env?: NodeJS.ProcessEnv }

/** mMac starts from Finder with a short PATH; Homebrew puts gh in one of these. */
export function ghEnvironment(env: NodeJS.ProcessEnv = process.env): NodeJS.ProcessEnv {
  return {
    ...env,
    PATH: [env.PATH, '/opt/homebrew/bin', '/usr/local/bin'].filter(Boolean).join(':'),
  }
}

async function gh(args: string[], cwd: string, options: Options = {}): Promise<string> {
  try {
    const { stdout } = await execute('gh', args, {
      cwd,
      env: ghEnvironment(options.env),
      maxBuffer: 16 * 1024 * 1024,
    })
    return stdout
  } catch (error) {
    const failure = error as NodeJS.ErrnoException & { stderr?: string }
    if (failure.code === 'ENOENT') throw new Error(GH_MISSING)
    const text = `${failure.stderr ?? ''}${failure.message}`
    if (/gh auth login|not logged in/i.test(text)) throw new Error(GH_SIGNED_OUT)
    throw new Error(text.trim() || 'gh failed.')
  }
}

const rollupSchema = z.array(
  z.object({
    __typename: z.string().optional(),
    name: z.string().optional(),
    context: z.string().optional(),
    status: z.string().optional(),
    conclusion: z.string().nullish(),
    state: z.string().optional(),
  }),
)
const rawSchema = z.object({
  number: z.number(),
  title: z.string(),
  url: z.string(),
  state: z.enum(['OPEN', 'CLOSED', 'MERGED']),
  isDraft: z.boolean(),
  reviewDecision: z.string().nullish(),
  mergeStateStatus: z.string().nullish(),
  baseRefName: z.string(),
  headRefName: z.string(),
  mergedAt: z.string().nullish(),
  mergeCommit: z.object({ oid: z.string() }).nullish(),
  body: z.string().nullish(),
  files: z.array(z.object({ path: z.string() })).nullish(),
  statusCheckRollup: rollupSchema.nullish(),
})
type Raw = z.infer<typeof rawSchema>

function check(entry: z.infer<typeof rollupSchema>[number]): PullRequestCheck {
  const name = entry.name ?? entry.context ?? 'check'
  if (entry.__typename === 'StatusContext' || (entry.state && !entry.status)) {
    const state = entry.state ?? ''
    return {
      name,
      state:
        state === 'SUCCESS' ? 'passing' : /PENDING|EXPECTED/.test(state) ? 'pending' : 'failing',
    }
  }
  if (entry.status !== 'COMPLETED') return { name, state: 'pending' }
  const conclusion = entry.conclusion ?? ''
  if (conclusion === 'SUCCESS') return { name, state: 'passing' }
  if (conclusion === 'NEUTRAL' || conclusion === 'SKIPPED') return { name, state: 'skipped' }
  return { name, state: 'failing' }
}

function toPullRequest(raw: Raw, live = false): PullRequest {
  return {
    number: raw.number,
    title: raw.title,
    url: raw.url,
    state: raw.state,
    isDraft: raw.isDraft,
    reviewDecision: raw.reviewDecision ?? null,
    mergeState: raw.mergeStateStatus ?? 'UNKNOWN',
    baseRefName: raw.baseRefName,
    headRefName: raw.headRefName,
    mergedAt: raw.mergedAt ?? null,
    checks: (raw.statusCheckRollup ?? []).map(check),
    body: raw.body ?? '',
    files: (raw.files ?? []).map((file) => file.path),
    live,
  }
}

/** The PR of the folder's current branch, or null when it has none. */
export async function prStatus(folder: string, options: Options = {}): Promise<PullRequest | null> {
  try {
    return toPullRequest(
      rawSchema.parse(JSON.parse(await gh(['pr', 'view', '--json', FIELDS], folder, options))),
    )
  } catch (error) {
    if (error instanceof Error && /no pull requests found/i.test(error.message)) return null
    throw error
  }
}

async function deployed(nwo: string, oid: string, folder: string, options: Options) {
  const deployments = z
    .array(z.object({ id: z.number() }))
    .parse(
      JSON.parse(
        await gh(['api', `repos/${nwo}/deployments?sha=${oid}&per_page=1`], folder, options),
      ),
    )
  if (!deployments.length) return false
  const statuses = z
    .array(z.object({ state: z.string() }))
    .parse(
      JSON.parse(
        await gh(
          ['api', `repos/${nwo}/deployments/${deployments[0].id}/statuses?per_page=1`],
          folder,
          options,
        ),
      ),
    )
  return statuses[0]?.state === 'success'
}

/** Open and recently merged PRs; closed-unmerged ones are dropped. */
export async function prList(project: string, options: Options = {}): Promise<PullRequest[]> {
  const raws = z
    .array(rawSchema)
    .parse(
      JSON.parse(
        await gh(
          ['pr', 'list', '--state', 'all', '--limit', '30', '--json', FIELDS],
          project,
          options,
        ),
      ),
    )
    .filter((raw) => raw.state !== 'CLOSED')
  const repo = z
    .object({ nameWithOwner: z.string(), defaultBranchRef: z.object({ name: z.string() }) })
    .parse(
      JSON.parse(
        await gh(['repo', 'view', '--json', 'nameWithOwner,defaultBranchRef'], project, options),
      ),
    )
  let checked = 0
  const result: PullRequest[] = []
  for (const raw of raws) {
    let live = false
    if (raw.state === 'MERGED') {
      if (raw.baseRefName === repo.defaultBranchRef.name) live = true
      else if (raw.mergeCommit && checked < DEPLOYMENT_CHECKS) {
        checked += 1
        live = await deployed(repo.nameWithOwner, raw.mergeCommit.oid, project, options).catch(
          () => false,
        )
      }
    }
    result.push(toPullRequest(raw, live))
  }
  return result
}

export async function prMerge(folder: string, number: number, options: Options = {}) {
  await gh(['pr', 'merge', String(number), '--squash'], folder, options)
}

export async function prMergeWhenReady(folder: string, number: number, options: Options = {}) {
  await gh(['pr', 'merge', String(number), '--auto', '--squash'], folder, options)
}
```

import Foundation
import MuseBackend

/// The PR monitor's rules: the checks summary, when to poll, and the Auto-fix prompt.
public enum PullRequestRules {
  public struct Summary: Equatable, Sendable {
    public let passing: Int
    public let failing: Int
    public let pending: Int
    public let text: String
  }

  public static func summary(_ checks: [PullRequestCheck]) -> Summary {
    let passing = checks.filter { $0.state == "passing" }.count
    let failing = checks.filter { $0.state == "failing" }.count
    let pending = checks.filter { $0.state == "pending" }.count
    let parts = [(passing, "passing"), (failing, "failing"), (pending, "pending")]
      .filter { $0.0 > 0 }.map { "\($0.0) \($0.1)" }
    return Summary(passing: passing, failing: failing, pending: pending, text: parts.isEmpty ? "No checks" : parts.joined(separator: ", "))
  }

  /// The first look always reads; after that, every 60 seconds while a PR exists and Changes shows.
  public static func shouldPoll(showingChanges: Bool, hasPullRequest: Bool, lastPoll: Date?, now: Date) -> Bool {
    guard showingChanges else { return false }
    guard let lastPoll else { return true }
    return hasPullRequest && now.timeIntervalSince(lastPoll) >= 60
  }

  public static func autoFixPrompt(_ pr: PullRequest) -> String {
    let failing = pr.checks.filter { $0.state == "failing" }.map(\.name)
    return """
      The CI checks of pull request \(pr.number) fail: \(failing.joined(separator: ", ")). \
      Read their logs with `gh run view --log-failed` (find the runs with `gh pr checks \(pr.number)`), \
      find the cause, fix it on this branch, and run the checks that fail locally before you push.
      """
  }
}

/// A pull request as a change card on a delivery track, for someone who does not follow Git.
public enum ChangeCardRules {
  public enum Step: Int, CaseIterable, Sendable {
    case drafted, checked, ready, accepted, live
    public var title: String {
      switch self {
      case .drafted: "Drafted"
      case .checked: "Checked"
      case .ready: "Ready for you"
      case .accepted: "Accepted"
      case .live: "Live"
      }
    }
  }
  public struct Track: Equatable, Sendable {
    public let step: Step
    /// A check fails: the Checked step shows red.
    public let failing: Bool
  }
  public enum Light: Sendable { case green, amber, red }
  public struct Risk: Equatable, Sendable {
    public let light: Light
    public let reason: String
    public init(light: Light, reason: String) {
      self.light = light
      self.reason = reason
    }
  }

  public static func track(_ pr: PullRequest) -> Track {
    if pr.state == "MERGED" { return Track(step: pr.live ? .live : .accepted, failing: false) }
    if pr.isDraft { return Track(step: .drafted, failing: false) }
    let failing = pr.checks.contains { $0.state == "failing" }
    let pending = pr.checks.contains { $0.state == "pending" }
    if failing || pending || !["CLEAN", "HAS_HOOKS"].contains(pr.mergeState) {
      return Track(step: .checked, failing: failing)
    }
    return Track(step: .ready, failing: false)
  }

  private static let redGroups: [(test: (String) -> Bool, reason: String)] = [
    ({ $0.hasPrefix("src/main/") || $0 == "src/headless/wire.ts" }, "changes how mMac talks to Muse"),
    ({ ["package.json", "package-lock.json", "Package.swift", "Package.resolved"].contains(($0 as NSString).lastPathComponent) }, "changes the dependencies"),
    ({ $0.hasPrefix(".github/workflows/") }, "changes the automated checks"),
    ({ $0.hasSuffix(".entitlements") || ($0 as NSString).lastPathComponent == "Info.plist" }, "changes the app\u{2019}s permissions"),
  ]

  private static func isDoc(_ path: String) -> Bool { path.hasSuffix(".md") || path.hasPrefix("docs/") }
  private static func isTest(_ path: String) -> Bool {
    path.hasPrefix("tests/") || path.contains("Tests/") || path.contains("Fixtures/")
  }

  /// From the changed paths only, never the code: red if any path is in a red group, green when
  /// every path is docs or tests, amber otherwise.
  public static func risk(_ paths: [String]) -> Risk {
    if paths.isEmpty { return Risk(light: .green, reason: "changes no files") }
    for group in redGroups where paths.contains(where: group.test) {
      return Risk(light: .red, reason: group.reason)
    }
    if paths.allSatisfy(isDoc) { return Risk(light: .green, reason: "touches only docs") }
    if paths.allSatisfy({ isDoc($0) || isTest($0) }) { return Risk(light: .green, reason: "touches only docs and tests") }
    return Risk(light: .amber, reason: "changes the app\u{2019}s code")
  }

  /// The open PR whose head branch is this PR's base: accept it first.
  public static func dependency(of pr: PullRequest, in prs: [PullRequest]) -> PullRequest? {
    prs.first { $0.state == "OPEN" && $0.number != pr.number && $0.headRefName == pr.baseRefName }
  }

  public static func blocker(of pr: PullRequest, in prs: [PullRequest]) -> String? {
    dependency(of: pr, in: prs).map { "Accept PR \($0.number) first" }
  }

  /// Newest first, with each PR after the one it depends on.
  public static func ordered(_ prs: [PullRequest]) -> [PullRequest] {
    var remaining = prs.sorted { $0.number > $1.number }
    var result: [PullRequest] = []
    while !remaining.isEmpty {
      let index = remaining.firstIndex { pr in
        guard let parent = dependency(of: pr, in: prs) else { return true }
        return result.contains { $0.number == parent.number }
      } ?? 0
      result.append(remaining.remove(at: index))
    }
    return result
  }

  /// One sentence for Dom: from "What changes for you" or "Summary", otherwise the title. Code
  /// blocks are skipped; Markdown marks are removed.
  public static func headline(title: String, body: String) -> String {
    var inCode = false
    var inSection = false
    for raw in body.components(separatedBy: "\n") {
      let line = raw.trimmingCharacters(in: .whitespaces)
      if line.hasPrefix("```") { inCode.toggle(); continue }
      if inCode { continue }
      if line.hasPrefix("#") {
        let heading = line.drop { $0 == "#" }.trimmingCharacters(in: .whitespaces).lowercased()
        inSection = heading == "what changes for you" || heading == "summary"
        continue
      }
      if inSection, !line.isEmpty { return firstSentence(plain(line)) }
    }
    return plain(title)
  }

  /// Images under "Before" and "After", otherwise up to the first two in the body.
  public static func pictures(_ body: String) -> [URL] {
    let pattern = #"!\[[^\]]*\]\(([^)\s]+)\)|<img[^>]*src="([^"]+)""#
    guard let regex = try? NSRegularExpression(pattern: pattern) else { return [] }
    func images(_ text: String) -> [URL] {
      regex.matches(in: text, range: NSRange(text.startIndex..., in: text)).compactMap { match in
        let range = match.range(at: 1).location != NSNotFound ? match.range(at: 1) : match.range(at: 2)
        return Range(range, in: text).flatMap { URL(string: String(text[$0])) }
      }
    }
    let sections = body.components(separatedBy: "\n#")
    let before = sections.first { $0.trimmingCharacters(in: CharacterSet(charactersIn: "# ")).lowercased().hasPrefix("before") }
    let after = sections.first { $0.trimmingCharacters(in: CharacterSet(charactersIn: "# ")).lowercased().hasPrefix("after") }
    let paired = [before, after].compactMap { $0.flatMap { images($0).first } }
    return paired.isEmpty ? Array(images(body).prefix(2)) : paired
  }

  public static func owner(of pr: PullRequest, worktrees: [WorktreeEntry]) -> String? {
    worktrees.first { ($0.branch ?? "").replacingOccurrences(of: "refs/heads/", with: "") == pr.headRefName }?
      .sessionIds.first
  }

  public static func askWhyPrompt(_ pr: PullRequest) -> String {
    """
    Explain pull request \(pr.number), "\(pr.title)", for someone who does not use Git. Say what changes \
    for them when it is accepted, why it was made, and what could go wrong. Use plain words and no code. \
    Read it with `gh pr view \(pr.number)` and `gh pr diff \(pr.number)`.
    """
  }

  public static func acceptedText(_ pr: PullRequest) -> String { "Accepted into \(pr.baseRefName)" }

  private static func plain(_ text: String) -> String {
    var result = text
    if result.hasPrefix("- ") || result.hasPrefix("* ") { result.removeFirst(2) }
    result = result.replacingOccurrences(of: #"\[([^\]]*)\]\([^)]*\)"#, with: "$1", options: .regularExpression)
    for mark in ["**", "__", "`"] { result = result.replacingOccurrences(of: mark, with: "") }
    return result.trimmingCharacters(in: .whitespaces)
  }

  private static func firstSentence(_ text: String) -> String {
    if let end = text.range(of: ". ") { return String(text[..<end.lowerBound]) + "." }
    return text
  }
}

```swift
extension Workspace {
  public func shouldPollPullRequest(showingChanges: Bool, now: Date) -> Bool {
    pullRequestError == nil
      && PullRequestRules.shouldPoll(
        showingChanges: showingChanges, hasPullRequest: pullRequest != nil, lastPoll: lastPullRequestPoll, now: now)
  }

  public func refreshPullRequest() async {
    guard let sessionId = view?.session.sessionId else { return }
    lastPullRequestPoll = .now
    do {
      pullRequest = try await client.pullRequest(sessionId: sessionId)
    } catch {
      pullRequestError = error.localizedDescription
    }
  }

  public func loadChangeCards() async {
    guard !project.isEmpty else { return }
    do {
      changeCards = try await client.pullRequests(project: project)
    } catch {
      errorMessage = error.localizedDescription
    }
  }

  public func accept(_ pr: PullRequest) async {
    var merged = false
    await run { merged = try await self.client.mergePullRequest(project: self.project, number: pr.number) }
    guard merged else { return }
    showNotice("PR merged")
    await loadChangeCards()
    if view != nil { await refreshPullRequest() }
  }

  public func mergeWhenReady(_ pr: PullRequest) async {
    guard let sessionId = view?.session.sessionId else { return }
    await run { _ = try await self.client.mergeWhenReady(sessionId: sessionId, number: pr.number) }
  }

  /// Auto-fix sends the prompt to the conversation; Muse is the agent.
  public func autoFix(_ pr: PullRequest) async {
    guard let sessionId = view?.session.sessionId else { return }
    let prompt = PullRequestRules.autoFixPrompt(pr)
    await run { try await self.client.send(sessionId: sessionId, text: prompt, effort: self.effort, mode: .queue) }
  }

  /// A plain explanation in a side chat on the conversation that owns the branch, or a new
  /// conversation in the project when none does.
  public func askWhy(_ pr: PullRequest) async {
    let prompt = ChangeCardRules.askWhyPrompt(pr)

      await open(owner)
      await openSideChat()
      await sendToSide(prompt)
    } else {
      startNew()
      draft = prompt
      _ = await send()
    }
  }
}
```
