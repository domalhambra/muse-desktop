# mMac M5a (session controls) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Muse Code, which Dom chose to run this plan, follows the same tasks in order with its own skills; every step names its files, its code and its check.

**Goal:** mMac gets the eight Claude Code Desktop features the parity spec puts in M5a: permission modes, a session shell, the context gauge with a changes badge and a Tasks tab, side chat, keyboard parity, the file context menu, an Agents tab, and a Preview tab.

**Architecture:** The Node host (`src/main/muse-host.ts`) gains three Muse calls (`session/setApprovalMode`, `session/sideChat`, `session/userShell`) and folds three events it ignored (`session/approvalModeChanged`, `session/contextUsage`, `session/todoListChanged`), after the pattern `listWorktrees` set. The backend (`src/headless/backend.ts`) exposes three methods. `MuseBackend` gets the typed calls and models. Every rule is pure Swift in `MuseKit` with a `swift test`. The app adds one picker, one transcript row, three inspector tabs, one sheet, one context menu and six menu items, on the views M1 to M4a built. The protocol number rises to 2.

**Status:** built on 2026-10-23 on the `mac-m5a` branch. Tasks 0 to 18 are done; Task 19 runs the review and opens the PR into `extensions`. Every feature has passing unit tests on both sides; `mac/scripts/ui-tests.sh 3` passed three runs, the real defaults `Unchanged`. The worktree moved to `~/mmac-m5a` mid-Task 17 because `~/Documents` made macOS ask for folder access on tool calls Dom could not answer while away. `mac/docs/testing.md` and `scripts/check.sh` do not exist in this repo, so Task 17 Step 5 and the Task 18 testing.md edits were skipped as written and recorded here. The live run and screenshots are M4b.

**Tech Stack:** TypeScript, zod, Vitest, `tsx`; Swift 6, SwiftUI (macOS 15), AppKit (`NSWorkspace`, `NSPasteboard`, `NSPopUpButton`), WebKit (`WKWebView`), Swift Testing, XCTest UI tests, XcodeGen.

**Inputs:**

- The spec, `docs/superpowers/specs/2026-10-23-mmac-parity-design.md`. It is the source for every decision below.
- The SDK's own types, `node_modules/@muse-code/sdk/dist/src/msp.d.ts` (1.4.7). Line numbers below are from that file.

**Dom's decisions for M5a (2026-10-23):**

- Eight features, in this order of value over cost: permission modes, session shell, context gauge with changes badge and Tasks tab, side chat, keyboard parity, file context menu, Agents tab, Preview tab. The plan follows that order after the backend tasks.
- Muse's own approval-mode names show in the Mode menu. Desktop's names mean other policies.
- The session shell is `!` in the composer, not a terminal pane.
- The preview pane takes a URL. It does not detect dev servers.
- Side sessions stay out of the sidebar and ⌘K.
- Diff line comments, view modes, split view, cloud and Remote Control are out.

```ts
  /**
   * Selects an approval mode for the session. Muse applies it to its next action; an action
   * already awaiting approval is not re-decided (msp.d.ts, `session/setApprovalMode`).
   */
  async setApprovalMode(sessionId: string, mode: ApprovalMode) {
    await this.resume(sessionId)
    const result = z
      .object({
        applyOutcome: z.string(),
        effectiveMode: z.object({ mode: z.string() }).passthrough(),
      })
      .parse(
        await this.connection.command(
          'session/setApprovalMode',
          { sessionId, mode },
          { maxAttempts: 1 },
        ),
      )
    this.requireSession(sessionId).view.session.approvalMode = result.effectiveMode
    this.schedule(sessionId)
    return result.effectiveMode.mode
  }
```

```ts
   * so it is hydrated loaded, like a created session. The caller shows it; it never joins the
   * sidebar (its kind is `sideChat`).
   */

    await this.resume(sessionId)
    const result = sessionResultSchema.parse(
      await this.connection.command('session/sideChat', { sessionId }, { maxAttempts: 1 }),
    )
    const live = await this.hydrate(result, true)
    return this.view(live)
  }

  /**
   * Runs a shell command in the session's folder, the TUI's `!` escape (msp.d.ts,
   * `session/userShell`). The result arrives as a `userShell` item through the item events.
   */
  async runShell(sessionId: string, commandText: string) {
    await this.resume(sessionId)
    await this.connection.command('session/userShell', { sessionId, commandText }, { maxAttempts: 1 })
  }
```

```swift
/// Muse's four approval modes, in the SDK's order (`ApprovalMode` in msp.d.ts). Closed: a client
/// selects one; it never defines one. The labels are Muse's own names as words, by Dom's decision.
public enum ApprovalMode: String, CaseIterable, Sendable, Identifiable {
  case allowAll, promptUnmatched, onRequest, denyUnmatched

  public var id: String { rawValue }

  public var label: String {

    case .promptUnmatched: "Prompt unmatched"

    }
  }
```

```swift
/// The inspector's context gauge, from `session/contextUsage`, as Desktop's Context card header.
public enum ContextGauge {
  public enum Tint: Equatable, Sendable { case normal, warning, blocked }

  /// Used over window, rounded, at most 100. Nil when Muse reports no window.
  public static func percent(_ usage: ContextUsage) -> Int? {
    guard let window = usage.window, window > 0 else { return nil }
    return min(100, Int((Double(usage.used) / Double(window) * 100).rounded()))
  }

  /// "Context 42%", or the token count when the model has no limit.
  public static func label(_ usage: ContextUsage) -> String {
    if let percent = percent(usage) { return "Context \(percent)%" }
    return "Context \(usage.used.formatted()) tokens"
  }

  public static func tint(_ usage: ContextUsage) -> Tint {
    switch usage.pressure {
    case "warning": .warning
    case "blocked": .blocked
    default: .normal
    }
  }
}

/// The toolbar's `+12 −1`: what the open conversation's tools changed, summed over their patch
/// summaries, as Desktop's Changes card counts the session's edits. Nil with nothing to show.
public enum ChangesBadge {
  public static func text(_ items: [TranscriptItem]) -> String? {
    ToolPresentation.groupPatch(items.filter { $0.retracted != true })
  }
}

/// One row of the Tasks tab: the agent's todo list, as Desktop's tasks pane shows it.
public struct TodoRow: Equatable, Sendable, Identifiable {
  public let id: Int
  public let text: String
  /// `pending`, `inProgress`, `completed` or `cancelled`.
  public let status: String
  public let activeForm: String?

  /// An in-progress row shows its present-tense form when the tool gave one.
  public var title: String { status == "inProgress" ? (activeForm ?? text) : text }

  public static func build(_ todos: [TodoItem]?) -> [TodoRow] {
    (todos ?? []).enumerated().map { index, todo in
      TodoRow(id: index, text: todo.text, status: todo.status, activeForm: todo.activeForm)
    }
  }
}
```

```swift
/// An app that can open a file, for the path menu's Open in.
public struct EditorApp: Equatable, Sendable, Identifiable {
  public let name: String
  public let bundleId: String
  public let url: URL
  public var id: String { bundleId }

  public init(name: String, bundleId: String, url: URL) {
    self.name = name
    self.bundleId = bundleId
    self.url = url
  }
}

/// The path context menu's rules, as Desktop's "Open files in other apps".
public enum FileMenuRules {
  /// Finder opens folders, not text; mMac is this app.
  public static let excludedBundleIds: Set<String> = ["com.apple.finder", "com.domalhambra.mmac"]

  public static func absolute(_ path: String, in project: String) -> URL {
    URL(fileURLWithPath: project, isDirectory: true).appending(path: path)
  }

  public static func fileName(_ path: String) -> String {
    path.split(separator: "/").last.map(String.init) ?? path
  }

  /// The apps to list, in the order given, without the excluded ones and without a second copy
  /// of the same app.
  public static func editors(_ apps: [EditorApp]) -> [EditorApp] {
    var seen = Set<String>()
    return apps.filter { !excludedBundleIds.contains($0.bundleId) && seen.insert($0.bundleId).inserted }
  }
}
```

```swift
/// One row of the Agents tab: a subagent the open conversation ran, as Desktop's tasks pane lists them.
public struct AgentRow: Equatable, Sendable, Identifiable {
  public let id: String
  public let title: String
  /// `controlStatus` when Muse gives one (`accepted`, `starting`, `running`, `resultReady`,
  /// `closing`, `closed`), else the item's status.
  public let status: String
  /// Duration and tokens, joined with " · ". Empty when the item has neither.
  public let detail: String
  public let childSessionId: String?

  public static func build(_ items: [TranscriptItem]) -> [AgentRow] {
    items.filter { $0.kind == "subagent" && $0.retracted != true }.map { item in
      var parts: [String] = []
      if let duration = item.durationMs { parts.append("\(ToolPresentation.fixed1(duration / 1000))s") }
      if let usage = item.usage { parts.append("\((usage.inputTokens + usage.outputTokens).formatted()) tokens") }
      return AgentRow(
        id: item.itemId,
        title: ToolPresentation.first(item.objective, item.label, item.role) ?? "Subagent",
        status: ToolPresentation.first(item.controlStatus) ?? item.status,
        detail: parts.joined(separator: " · "),
        childSessionId: item.childSessionId)
    }
  }

  /// Whether the row's status means running, done, or neither, for the icon.
  public var phase: Phase {
    switch status {
    case "accepted", "starting", "running", "inProgress": .running
    case "closed", "resultReady", "completed": .done
    default: .other
    }
  }

  public enum Phase: Equatable, Sendable { case running, done, other }
}
```

```swift
/// The Preview tab's rules. The tab takes a typed address; it does not detect dev servers.
public enum PreviewRules {
  /// A typed address as a URL: a bare host or `host:port` gets `http://`. Only `http`, `https` and
  /// `file` load. Nil for an empty field, another scheme, or `http://` with no host.
  public static func url(from text: String) -> URL? {
    let trimmed = text.trimmingCharacters(in: .whitespacesAndNewlines)
    guard !trimmed.isEmpty else { return nil }
    let withScheme = trimmed.contains("://") ? trimmed : "http://" + trimmed
    guard let url = URL(string: withScheme), let scheme = url.scheme?.lowercased() else { return nil }
    switch scheme {
    case "http", "https": return url.host == nil ? nil : url
    case "file": return url
    default: return nil
    }
  }

  /// The defaults key that remembers a project's last preview address.
  public static func key(for project: String) -> String { "preview-url:\(project)" }
}
```

```swift
/// One `WKWebView` and what the toolbar reads from it. `@Observable`, so the buttons follow it.
@MainActor @Observable
final class WebPage {
  let view = WKWebView()
  private(set) var title = ""
  private(set) var url: URL?
  private(set) var canGoBack = false
  private let watcher = Watcher()

  init() {
    watcher.onChange = { [weak self] in self?.read() }
    view.navigationDelegate = watcher
  }

  func load(_ url: URL, failed: @escaping (String) -> Void) {
    watcher.onFailure = failed
    if url.isFileURL {
      view.loadFileURL(url, allowingReadAccessTo: url.deletingLastPathComponent())
    } else {
      view.load(URLRequest(url: url))
    }
  }

  func goBack() { view.goBack() }
  func reload() { view.reload() }

  private func read() {
    title = view.title ?? ""
    url = view.url
    canGoBack = view.canGoBack
  }

  /// The navigation delegate: a plain object, since WebKit calls it on the main thread.
  private final class Watcher: NSObject, WKNavigationDelegate {
    var onChange: () -> Void = {}
    var onFailure: (String) -> Void = { _ in }
    func webView(_ webView: WKWebView, didFinish navigation: WKNavigation!) { onChange() }
    func webView(_ webView: WKWebView, didFail navigation: WKNavigation!, withError error: any Error) {
      onFailure(error.localizedDescription)
      onChange()
    }
    func webView(_ webView: WKWebView, didFailProvisionalNavigation navigation: WKNavigation!, withError error: any Error) {
      onFailure(error.localizedDescription)
      onChange()
    }
  }
}

struct WebViewBox: NSViewRepresentable {
```
