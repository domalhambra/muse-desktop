# mMac M3 (Settings) Implementation Plan

**Status:** planned on 2026-10-22. Not built yet.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** mMac gets a native macOS Settings window with four panes: Appearance (the Muse and Moonlight themes, text size, Reduce motion, completion notifications), Muse Code (path, connection status, reconnect), MCP servers (list, add, turn on or off, remove, sign in through `muse mcp login`) and Bridges (folder bridge and MCP bridge, with the token in the login Keychain). M3 also closes every item M2 carried forward, and ends with the UI tests and the live isolated run for M2 and M3 together.

**Architecture:** The Node backend gains the seven Settings methods (`mcp-list`, `mcp-add`, `mcp-enabled`, `mcp-remove`, `mcp-login`, `bridge-status`, `bridge-token`) and runs both bridges. They call the fork's existing `src/main/mcp-config.ts`, `bridge-files.ts`, `bridge-mcp.ts` and `agent-api.ts` unchanged. `start` takes the bridge token, which mMac reads from the login Keychain; a new token goes back to the Keychain. `MuseBackend` gets the typed Swift calls and models. `MuseKit` gets pure Settings rules (form parsing, port, themes, text sizes, the completion notice) and a `SettingsModel` store, both under `swift test`. The app adds a SwiftUI `Settings` scene, applies the theme and text size at the root, and posts completion notifications with `UserNotifications`.

**Tech Stack:** TypeScript, zod, Vitest, `tsx`; Swift 6, SwiftUI (macOS 15), AppKit (`NSAlert`, `NSOpenPanel`, `NSWorkspace`, `NSPasteboard`), Security (Keychain), UserNotifications, Swift Testing, XCUITest, XcodeGen.

**Inputs:** the spec `docs/superpowers/specs/2026-10-21-mac-app-design.md` (the M3 row, the five (M3) parity items, the "What moves from the backend to the app" table), the M2 plan's "Carried into M3" section in `docs/superpowers/plans/2026-10-21-mmac-m2.md`, `docs/decisions.md`, `docs/bridge.md`, and Electron's Settings: `src/renderer/src/components/Settings.tsx`, `McpSettings.tsx`, `BridgeSettings.tsx`, `src/renderer/src/tokens.css`, and the handlers in `src/main/index.ts` (`emit` for notifications, `syncBridges`, `bridgeStatus`, `openProjectTerminal`, the `mcp-*` and `bridge-*` channels). When this plan quotes a user-facing string, it comes from those files.

**Dom's decisions for M3 (2026-10-22):**

- The M2 UI tests and the M2 live isolated run happen at the end of M3, in one run that covers M2 and M3 (Task 16).
- mMac's bridges use mMac's own folder, `~/Library/Application Support/mMac/bridge`, and the same default port as Electron, 7735. Dom runs one app's MCP bridge at a time. A clash shows Electron's "Port 7735 is in use. Choose another port."
- Appearance has the spec's scope: the theme (Muse or Moonlight), text size (compact, comfortable, large), Reduce motion and Completion notifications. No light mode, no "Follow macOS appearance", no background intensity.
- M3 closes every item in M2's "Carried into M3" list.

**Choices this plan makes where Electron is the default (Task 18 records each in `docs/decisions.md`):**

- Settings is the macOS Settings window (Command-comma), with a toolbar of four panes. Electron's About pane is left out: macOS gives mMac its own About panel, and Sparkle is off for v1.
- A completion notification opens its conversation when clicked. Electron only shows the window.
- A preference theme other than `muse` or `moonlight` (from an older file) shows as Muse, except `system`, which shows as Moonlight: Electron shows Moonlight for `system` on a dark Mac, and mMac has no light theme.
- The worktree toggle shows only when the current project is a Git repository (M2 carried item). Electron shows it with no project too.
- **Revert hunk** sends the hunk's text, and the backend refuses when the file's hunk no longer matches (M2 carried item). Electron has the same gap and no guard.
- Debug builds take `MMAC_KEYCHAIN_SERVICE`, so test runs never read or write Dom's bridge token.

```ts
import { execFile } from 'node:child_process'
import { promisify } from 'node:util'

// Terminal, as src/main/index.ts's openProjectTerminal opens it on macOS. mMac runs only on macOS.

export type Run = (file: string, args: string[], options: { timeout: number }) => Promise<unknown>

const quote = (value: string) => `'${value.replaceAll("'", "'\\''")}'`

/** The line Terminal runs: change to `folder`, then run the CLI with `cliArgs`. */
export function terminalCommand(folder: string, cli: string, cliArgs: string[]) {
  return `cd ${quote(folder)} && ${[cli, ...cliArgs].map(quote).join(' ')}`
}

/** Opens Terminal and runs `command`. argv carries it as data; nothing is put into AppleScript. */
export async function openInTerminal(command: string, run: Run = promisify(execFile)) {
  await run(
    '/usr/bin/osascript',
    [
      '-e',
      'on run argv',
      '-e',
      'tell application "Terminal"',
      '-e',
      'activate',
      '-e',
      'do script (item 1 of argv)',
      '-e',
      'end tell',
      '-e',
      'end run',
      command,
    ],
    { timeout: 10000 },
  )
}
```

Prettier reflows the argument list; that is fine.

### Task 2: The bridges in the backend, with the token from `start`

**Goal:** The backend runs the folder bridge and the MCP bridge as Electron's `syncBridges` does, with mMac's own bridge folder and a token that mMac sends in `start` and gets back from `bridge-token`.

**Files:**

- Create: `src/headless/bridges.ts`
- Modify: `src/headless/backend.ts`, `src/headless/server.ts`, `scripts/verify-headless.ts`
- Test: `tests/unit/headless-bridges.test.ts` (new), `tests/unit/headless-backend.test.ts`, `tests/unit/headless-parity.test.ts`

**Acceptance Criteria:**

- [ ] `start` accepts `{ dataFolder, bridgeToken? }`. The token is a string of at most 256 characters and is kept in memory only. It never goes into `preferences.json`, an event or a log line.
- [ ] After `start` connects, the bridges match the preferences. Saving a `bridge*` preference syncs them again, in one serialized chain.
- [ ] The bridge folder is `<dataFolder>/bridge`.
- [ ] `bridge-status` returns Electron's `BridgeStatus`: `folder`, `files {enabled, running, error?}`, `mcp {enabled, running, url, hasToken, error?}`, `activeJobs`.
- [ ] A port in use reports "Port N is in use. Choose another port." as `mcp.error`.
- [ ] `bridge-token` makes a new `randomBytes(24)` base64url token, restarts a running MCP bridge with it, and returns it.
- [ ] The quit path stops both bridges before it exits.
- [ ] An agent request for a project that is not trusted fails with "That project is not trusted in mMac. Open it there first."
- [ ] With the real `McpBridge` on a free port: no token gives HTTP 401; the token gives a reply.
- [ ] `npm run test:headless` also checks that `start` with a token and `bridge-status` work against the real CLI, and that no bridge port stays open after shutdown.
- [ ] The parity test moves `bridge-status` and `bridge-token` from `notYet` and counts 36 headless methods.

```ts
import type { AgentApi } from '../main/agent-api'
import { FileBridge } from '../main/bridge-files'
import { McpBridge } from '../main/bridge-mcp'
import { messageOf } from '../main/muse-host'
import type { BridgeStatus, Preferences } from '../shared/protocol'

// mMac's bridges: the folder bridge and the localhost MCP bridge, started and stopped as the
// preferences say. This repeats syncBridges and bridgeStatus in src/main/index.ts, with mMac's own
// folder, and a token mMac keeps in the login Keychain and sends in `start`. The token lives in
// memory here and nowhere else.

type Startable = { start(): Promise<void>; stop(): Promise<void> }

export type BridgeFactories = {
  files: (root: string, api: AgentApi) => Startable
  mcp: (
    api: AgentApi,
    options: { port: number; token: string; projects: () => string[] },
  ) => Startable
}

export const realBridges: BridgeFactories = {
  files: (root, api) => new FileBridge(root, api),
  mcp: (api, options) => new McpBridge(api, options),
}

export type BridgesOptions = {
  root: string
  token: string
  api: AgentApi
  preferences: () => Preferences
  factories?: BridgeFactories
}

export class Bridges {
  private files?: Startable
  private mcp?: { bridge: Startable; port: number; token: string }
  private errors: { files?: string; mcp?: string } = {}
  private chain: Promise<void> = Promise.resolve()
  private stopped = false
  private token: string
  private readonly factories: BridgeFactories

  constructor(private readonly options: BridgesOptions) {
    this.token = options.token
    this.factories = options.factories ?? realBridges
  }

  get hasToken() {
    return Boolean(this.token)
  }

  /** Takes a new token. The next sync restarts a running MCP bridge with it. */
  setToken(token: string) {
    this.token = token
  }

  /** Brings both bridges in line with the preferences. Calls run one after another. */
  sync() {
    this.chain = this.chain.then(() => this.apply())
    return this.chain
  }

  /** Stops both bridges for good: the quit path. */
  stop() {
    this.stopped = true
    return this.sync()
  }

  private async apply() {
    const preferences = this.options.preferences()
    const { api, root } = this.options
    const wantFiles = preferences.bridgeFilesEnabled && !this.stopped
    if (wantFiles && !this.files) {
      const bridge = this.factories.files(root, api)
      try {
        await bridge.start()
        this.files = bridge
        delete this.errors.files
      } catch (error) {
        await bridge.stop().catch(() => {})
        this.errors.files = messageOf(error)
      }
    } else if (!wantFiles && this.files) {
      await this.files.stop().catch(() => {})
      this.files = undefined
    }
    if (!wantFiles) delete this.errors.files

    const wantMcp = preferences.bridgeMcpEnabled && !this.stopped
    const port = preferences.bridgeMcpPort
    const token = this.token
    if (this.mcp && (!wantMcp || this.mcp.port !== port || this.mcp.token !== token)) {
      await this.mcp.bridge.stop().catch(() => {})
      this.mcp = undefined
    }
    if (wantMcp && !this.mcp) {
      const bridge = this.factories.mcp(api, {
        port,
        token,
        projects: () => {
          const current = this.options.preferences()
          return current.recentProjects.filter((project) =>
            current.trustedProjects.includes(project),
          )
        },
      })
      try {
        await bridge.start()
        this.mcp = { bridge, port, token }
        delete this.errors.mcp
      } catch (error) {
        await bridge.stop().catch(() => {})
        this.errors.mcp =
          error instanceof Error && 'code' in error && error.code === 'EADDRINUSE'
            ? `Port ${port} is in use. Choose another port.`
            : messageOf(error)
      }
    } else if (!wantMcp) delete this.errors.mcp
  }

  async status(): Promise<BridgeStatus> {
    await this.chain
    const preferences = this.options.preferences()
    return {
      folder: this.options.root,
      files: {
        enabled: preferences.bridgeFilesEnabled,
        running: Boolean(this.files),
        ...(this.errors.files ? { error: this.errors.files } : {}),
      },
      mcp: {
        enabled: preferences.bridgeMcpEnabled,
        running: Boolean(this.mcp),
        url: `http://127.0.0.1:${preferences.bridgeMcpPort}/mcp`,
        hasToken: this.hasToken,
        ...(this.errors.mcp ? { error: this.errors.mcp } : {}),
      },
      activeJobs: this.options.api.activeCount,
    }
  }
}
```

```swift
/// The Settings window's rules. Electron keeps them in `McpSettings.tsx`, `BridgeSettings.tsx`,
/// `Settings.tsx` and `tokens.css`.
public enum SettingsRules {
  public static let portError = "Use a port between 1024 and 65535."

  /// One `KEY=value` (env) or `Name: value` (headers) pair per line, as Electron's `parsePairs`.
  public static func pairs(_ text: String, separator: Character) throws -> [String: String] {
    var pairs: [String: String] = [:]
    for line in text.split(separator: "\n", omittingEmptySubsequences: false) {
      let trimmed = line.trimmingCharacters(in: .whitespaces)
      if trimmed.isEmpty { continue }
      guard let index = trimmed.firstIndex(of: separator), index > trimmed.startIndex else {
        throw WorkspaceError("Write each line as name\(separator)value: \(trimmed)")
      }
      let key = trimmed[..<index].trimmingCharacters(in: .whitespaces)
      let value = trimmed[trimmed.index(after: index)...].trimmingCharacters(in: .whitespaces)
      pairs[key] = value
    }
    return pairs
  }

  /// The bridge port typed in the field, or nil when it is not a whole number from 1024 to 65535.
  public static func port(_ text: String) -> Int? {
    guard let value = Int(text.trimmingCharacters(in: .whitespaces)), (1024...65535).contains(value) else {
      return nil
    }
    return value
  }
}
```

```swift
import Foundation
import Security

/// Where mMac keeps the MCP bridge's token. The backend holds it in memory only.
public protocol BridgeTokenStore: Sendable {
  func read() throws -> String?
  func write(_ token: String) throws
}

/// The token as a generic password in the login Keychain.
public struct KeychainTokenStore: BridgeTokenStore {
  public let service: String
  public let account: String

  public init(service: String, account: String) {
    self.service = service
    self.account = account
  }

  /// mMac's own item. Debug builds take `MMAC_KEYCHAIN_SERVICE`, so test runs never touch it.
  public static var app: KeychainTokenStore {
    #if DEBUG
      if let service = ProcessInfo.processInfo.environment["MMAC_KEYCHAIN_SERVICE"], !service.isEmpty {
        return KeychainTokenStore(service: service, account: "mcp-bridge")
      }
    #endif
    return KeychainTokenStore(service: "com.domalhambra.mmac.bridge-token", account: "mcp-bridge")
  }

  private var query: [String: Any] {
    [kSecClass as String: kSecClassGenericPassword, kSecAttrService as String: service, kSecAttrAccount as String: account]
  }

  public func read() throws -> String? {
    var query = self.query
    query[kSecReturnData as String] = true
    query[kSecMatchLimit as String] = kSecMatchLimitOne
    var result: CFTypeRef?
    let status = SecItemCopyMatching(query as CFDictionary, &result)
    if status == errSecItemNotFound { return nil }
    guard status == errSecSuccess, let data = result as? Data else { throw Self.error(status) }
    return String(decoding: data, as: UTF8.self)
  }

  public func write(_ token: String) throws {
    let data = Data(token.utf8)
    let status = SecItemUpdate(query as CFDictionary, [kSecValueData as String: data] as CFDictionary)
    if status == errSecItemNotFound {
      var add = query
      add[kSecValueData as String] = data
      add[kSecAttrLabel as String] = "mMac MCP bridge token"
      let added = SecItemAdd(add as CFDictionary, nil)
      guard added == errSecSuccess else { throw Self.error(added) }
    } else if status != errSecSuccess {
      throw Self.error(status)
    }
  }

  /// Removes the item. Tests use it to clean up.
  public func delete() throws {
    let status = SecItemDelete(query as CFDictionary)
    guard status == errSecSuccess || status == errSecItemNotFound else { throw Self.error(status) }
  }

  private static func error(_ status: OSStatus) -> WorkspaceError {
    WorkspaceError(SecCopyErrorMessageString(status, nil) as String? ?? "Keychain error \(status).")
  }
}

/// A token store in memory, for tests and previews.
public final class MemoryTokenStore: BridgeTokenStore {
  private let token: Mutex<String?>
  public init(_ token: String? = nil) { self.token = Mutex(token) }
  public func read() throws -> String? { token.withLock { $0 } }
  public func write(_ token: String) throws { self.token.withLock { $0 = token } }
}
```

```swift
  public func loadServers() async {

    do {
      let list = try await client.mcpList()
      guard sequence == listSequence else { return }
      servers = list.servers
      settingsFile = list.file
    } catch {
      guard sequence == listSequence else { return }
      errorMessage = error.localizedDescription
    }
  }

  public func addServer(_ form: McpForm) async -> Bool {
    await change { try await self.client.mcpAdd(try form.input()) }
  }

  public func setEnabled(_ name: String, _ enabled: Bool) async {
    await change { try await self.client.mcpSetEnabled(name, enabled) }
  }

  /// The view asks "Remove the MCP server <name>?" first.
  public func remove(_ name: String) async {
    await change { try await self.client.mcpRemove(name) }
  }

  /// Opens Terminal on `muse mcp login`. Nothing reports back, as in Electron.
  public func signIn(_ name: String) async {
    do { try await client.mcpLogin(name) } catch { errorMessage = error.localizedDescription }
  }

  public func reconnect() async {
    await workspace.reconnect()
    needsReconnect = false
  }

  @discardableResult
  private func change(_ work: () async throws -> Void) async -> Bool {
    do {
      try await work()
    } catch {
      errorMessage = error.localizedDescription
      return false
    }
    needsReconnect = true
    await loadServers()
    return true
  }

  // MARK: Bridges

  public func refreshBridge() async {
    do { bridge = try await client.bridgeStatus() } catch { errorMessage = error.localizedDescription }
  }

  /// Saves a preference, and reads the bridge status again when it was a bridge field.
  public func save(_ patch: PreferencesPatch) async {
    guard await workspace.save(patch) else { return }
    if patch.touchesBridges { await refreshBridge() }
  }

  /// Saves the typed port. Returns the text the field should show: the saved port when the typed
  /// one is refused.
  public func savePort(_ text: String) async -> String {
    guard let port = SettingsRules.port(text) else {
      errorMessage = SettingsRules.portError
      return String(workspace.preferences.bridgeMcpPort)
    }
    await save(PreferencesPatch(bridgeMcpPort: port))
    return String(workspace.preferences.bridgeMcpPort)
  }

  public func makeToken() async {
    let token: String
    do {
      token = try await client.bridgeNewToken()
    } catch {
      errorMessage = error.localizedDescription
      return
    }
    newToken = token
    do {
      try tokens.write(token)
    } catch {
      errorMessage = "mMac could not save the token in the Keychain: \(error.localizedDescription)"
    }
    await refreshBridge()
  }

  /// The saved token, for Copy token.
  public func copyToken() throws -> String {
    guard let token = try tokens.read(), !token.isEmpty else { throw WorkspaceError("Make a token first.") }
    return token
  }
}
```

```swift
extension DiffLine {
  /// The longest diff line shown whole. Longer lines, such as minified files, show cut.
  public static let longLine = 2_000

  /// A diff line as the diff view shows it.
  public static func display(_ text: String) -> String {
    text.count > longLine ? String(text.prefix(longLine)) + "…" : text
  }

  /// The hunks of a raw `git diff`, exactly as `splitHunks` in src/main/git.ts cuts them.
  public static func rawHunks(_ raw: String) -> [String] {
    var text = Substring(raw)
    if text.hasSuffix("\n") { text = text.dropLast() }
    let lines = text.split(separator: "\n", omittingEmptySubsequences: false)
    guard let start = lines.firstIndex(where: { $0.hasPrefix("@@") }) else { return [] }
    var hunks: [String] = []
    var current: [Substring] = []
    for line in lines[start...] {
      if line.hasPrefix("@@"), !current.isEmpty {
        hunks.append(current.joined(separator: "\n"))
        current = []
      }
      current.append(line)
    }
    if !current.isEmpty { hunks.append(current.joined(separator: "\n")) }
    return hunks
  }
}

  public static func counted(_ title: String, _ count: Int) -> String { count > 0 ? "\(title) \(count)" : title }
}
```

```swift
import AppKit
import MuseBackend
import MuseKit
@preconcurrency import UserNotifications

/// Completion notifications. Electron posts them from its main process; mMac posts them here.
@MainActor
final class Notifications: NSObject, UNUserNotificationCenterDelegate {
  /// Opens a conversation when its notification is clicked. AppController sets it.
  var openConversation: ((String) -> Void)?
  private(set) var denied = false

  override init() {
    super.init()
    UNUserNotificationCenter.current().delegate = self
  }

  /// Asks macOS once; later calls return the saved answer.
  func requestPermission() async -> Bool {
    let granted = (try? await UNUserNotificationCenter.current().requestAuthorization(options: [.alert, .sound])) ?? false
    denied = !granted
    return granted
  }

  func post(for session: Session) {
    let notice = CompletionNotice.content(for: session)
    let content = UNMutableNotificationContent()
    content.title = notice.title
    content.body = notice.body
    content.sound = .default
    content.userInfo = ["sessionId": session.sessionId]
    UNUserNotificationCenter.current().add(
      UNNotificationRequest(identifier: session.sessionId, content: content, trigger: nil))
  }

  nonisolated func userNotificationCenter(
    _ center: UNUserNotificationCenter, didReceive response: UNNotificationResponse
  ) async {
    guard let sessionId = response.notification.request.content.userInfo["sessionId"] as? String else { return }
    await MainActor.run { openConversation?(sessionId) }
  }
}
```

```swift
/// Electron's Bridges tab. The token lives in the login Keychain.
struct BridgesPane: View {

        }
        .toggleStyle(.switch)
        if let folder = settings.bridge?.folder {
          Text(folder).font(.caption.monospaced()).textSelection(.enabled)
          Button("Open bridge folder") { openFolder(folder) }
          Text("Give the README.md in that folder to the other agent as its instructions.")

        }
      }

        }
        .toggleStyle(.switch)
        .disabled(settings.bridge?.mcp.hasToken != true && !preferences.bridgeMcpEnabled)
        if let url = settings.bridge?.mcp.url { Text(url).font(.caption.monospaced()).textSelection(.enabled) }
        TextField("Port", text: $port)
          .focused($portFocused)
          .onSubmit { Task { port = await settings.savePort(port) } }
          .onChange(of: portFocused) { _, focused in if !focused { Task { port = await settings.savePort(port) } } }
        if let token = settings.newToken {
          LabeledContent("New token, shown once") { Text(token).font(.body.monospaced()).textSelection(.enabled) }
        }
        HStack {
          Button(settings.bridge?.mcp.hasToken == true ? "Make new token" : "Make token") { Task { await makeToken() } }
          Button("Copy token") { copy() }
        }
      }
    }
    .formStyle(.grouped)
    .onAppear { port = String(preferences.bridgeMcpPort) }
    .task {
      while !Task.isCancelled {
        await settings.refreshBridge()
        try? await Task.sleep(for: .seconds(2))
      }
    }
    .onDisappear { settings.clearNewToken() }
  }

  private func binding(_ value: Bool, patch: @escaping (Bool) -> PreferencesPatch) -> Binding<Bool> {
    Binding(get: { value }, set: { next in Task { await settings.save(patch(next)) } })
  }

  private var mcpState: String { state(settings.bridge.map { .init(enabled: $0.mcp.enabled, running: $0.mcp.running, error: $0.mcp.error) }) }

  private func state(_ part: BridgeStatus.Part?) -> String {
    if let error = part?.error { return "Not running: \(error)" }
    return part?.running == true ? "Running" : "Off"
  }

  private func makeToken() async {
    if settings.bridge?.mcp.hasToken == true {
      let choice = await SheetAlert.confirm(
        title: "Make a new token?", message: "Agents using the current token lose access.",
        buttons: ["Make new token", "Cancel"])
      guard choice == 0 else { return }
    }
    await settings.makeToken()
  }

  private func copy() {
    do {
      let token = try settings.copyToken()
      NSPasteboard.general.clearContents()
      NSPasteboard.general.setString(token, forType: .string)
    } catch {
      settings.errorMessage = error.localizedDescription
    }
  }

  private func openFolder(_ folder: String) {
    do {
      try FileManager.default.createDirectory(
        atPath: folder, withIntermediateDirectories: true, attributes: [.posixPermissions: 0o700])
      NSWorkspace.shared.open(URL(fileURLWithPath: folder))
    } catch {
      settings.errorMessage = error.localizedDescription
    }
  }
}
```
