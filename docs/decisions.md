# Decisions

Decisions made in Dom's fork, newest last. Each row gives the decision, the reason and the source. A reversed decision stays here, marked superseded, and the new one goes under its own date. Upstream's own design choices are in `architecture.md` and `design.md`, not here.

Dates are Dom's local time (Pacific). The cloud session's commits carry UTC times from the evening of 2026-10-20, so they read as 2026-10-21 in `git log`.

## 2026-10-20: the Mac setup

| Decision                                                                                                                                                      | Why                                                                                                                                                                                                                                              | Source                                                |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------- |
| `main` mirrors upstream's `main` and moves only by `git merge --ff-only upstream/main`. Features go on branches into the fork's `main` by PR, and Dom merges. | A clean mirror keeps every upstream sync a fast-forward.                                                                                                                                                                                         | Session log, 2026-10-20                               |
| The clone's push URL for `upstream` is `no-push-to-upstream`, and `gh repo set-default` names the fork.                                                       | `gh pr create` in a fork targets upstream by default. Neither remote should get a stray push or PR.                                                                                                                                              | Session log, 2026-10-20                               |
| Run the fork from the checkout. Do not package it for daily use.                                                                                              | A packaged build keeps upstream's `appId` and update feed. It would share the installed app's data folder, and an update would replace it with upstream's build. `CONTRIBUTING.md` forbids distributing a fork that points at the upstream feed. | `electron-builder.yml`, `scripts/sparkle-config.json` |
| `npm run dev:isolated` gives dev builds their own data folder.                                                                                                | Dev builds then never change an installed app's preferences.                                                                                                                                                                                     | PR 2                                                  |
| The MCP servers e2e test records the status text and waits for Connecting, then Connected, after Reconnect.                                                   | The old wait passed at once, the app quit mid-reconnect, and an orphaned `muse --version` broke sandbox cleanup in about one run in five on macOS.                                                                                               | `c019a9b`                                             |

## 2026-10-21: mMac M0

| Decision                                                                                                                                                                                                          | Why                                                                                                                                                                                  | Source                                                            |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| `mac/project.yml` is committed. XcodeGen generates the Xcode project and its Info.plist, which `mac/.gitignore` keeps out of git.                                                                                 | A hand-edited project.pbxproj conflicts and drifts. The YAML is short and reviewable.                                                                                                | `docs/superpowers/plans/2026-10-21-mmac-m0.md`, Task 7; `f7b0466` |
| In M0, mMac runs the backend from the checkout with `node --import tsx src/headless/server.ts`.                                                                                                                   | No build step for the backend while it changes every milestone. A bundled build comes with distribution, which is out of scope.                                                      | Task 6; `d4c4f50`                                                 |
| An Ask's last button cancels and is the default.                                                                                                                                                                  | It matches every Electron dialog the Asks replace (`defaultId` and `cancelId` on the last button).                                                                                   | Task 1; `837d22d`                                                 |
| `MMAC_DATA_FOLDER` overrides mMac's data folder.                                                                                                                                                                  | Test runs keep mMac's preferences out of `~/Library/Application Support/mMac`, as `MUSE_DESKTOP_USER_DATA` does for Desktop.                                                         | Task 7; `f7b0466`                                                 |
| mMac waits up to 6 seconds for the login shell's PATH. A shell still running then gets SIGKILL, and mMac goes on without its PATH. A shell that exited while a child holds its stdout open gives what it printed. | An interactive shell ignores SIGTERM, and a child of the shell can hold its stdout open. A plain timeout can hang.                                                                   | `d4c4f50`                                                         |
| A request that is not valid but has a readable `id` gets an `ok: false` Reply. Only a line with no readable `id` becomes an error Event.                                                                          | mMac waits on that `id`. Without a Reply, its call never returns.                                                                                                                    | `38c1848`                                                         |
| An Ask mMac cannot read is answered with -1.                                                                                                                                                                      | The backend waits on every Ask. -1 is the cancel choice, so the waiting method stops safely.                                                                                         | `601486f`                                                         |
| `BackendClient` answers every Ask from inside its actor, and a choice outside the Ask's buttons becomes -1.                                                                                                       | Every write to the backend then runs on the actor, so an answer never goes out after the client stops. The backend never gets a button that does not exist.                          | `601486f`                                                         |
| `npm run test:headless` checks only the `muse serve` processes that its own backends started. It sets `MUSE_NO_AUTO_UPDATE=1` and points `ZDOTDIR` at its temporary folder.                                       | A global process count gave false passes and fails when other suites ran. The `muse` launcher otherwise starts an update check, and a login shell otherwise reads the real dotfiles. | `503bf85`, `0be9db0`                                              |
| `attachments` stays a backend method, on the parity test's `notYet` list, not on `electronOnly`.                                                                                                                  | The backend checks each attachment's size and type before a send uses it. mMac shows the panel and sends the paths.                                                                  | `4140037`                                                         |

## Rejected and deferred

| Item                                                                                 | Status   | Why                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------ | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `MuseHost.close()` stopping a connection that is still starting                      | Deferred | Upstream's code. This is harmless outside tests, and the e2e fix removed the only symptom.                                       |
| Opening PRs upstream                                                                 | Deferred | Only when Dom asks. | The second launch in `tests/e2e/setup.spec.ts` does not set `XDG_CONFIG_HOME`        | Deferred | Upstream's test. It reaches the real Muse config only when the developer has `XDG_CONFIG_HOME` set. It is unset on Dom's Mac, and checksums of `~/.config/muse` matched before and after every run. A fix belongs upstream. |
| `src/main/cli.ts` `discoverCli` stops the login shell with SIGTERM after 6 seconds   | Deferred | Upstream's code. A fix belongs upstream.                                                                                 |
